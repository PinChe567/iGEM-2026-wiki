Define what a fluorescence percentage measures

  1. Home
  2. Dry Lab
  3. Measurement

Abstract

Crowded HEK293 images make a fluorescence percentage hard to interpret: the denominator is unclear. We measured reporter-associated local contrast around resolvable DAPI objects and recorded every exclusion. The archive contains 25 fields, 12 condition labels and 2,624 eligible objects. Accepted objects cover only 7.1–20.9% of segmented DAPI foreground across receptor conditions. This is an exploratory expression screen, not a measure of transfection efficiency.

This page specifies the reproducible pipeline, its control audit and a concrete failure mode: broad field fluorescence and local object contrast can disagree. It links the exact input CSVs, script, parameters and hashes so another team can reproduce or challenge the analysis. Quantitative findings and all acquired images remain in Results.

Define the numerator and denominator

The numerator is the number of eligible DAPI-connected objects whose reporter score exceeds a channel-specific blank threshold. The denominator is all objects passing the same geometric and background rules. An accepted object is not guaranteed to represent exactly one cell; excluded aggregates can contain many cells. Neither fluorescent pixel area nor this selected-object fraction estimates the fraction of all live cells transfected.

GCaMP6f depends on calcium and reporter abundance, so a dim resting endpoint is not an expression-negative control. Time-resolved stimulation is a different measurement. [1] We separate original acquisition, computational scoring and display adjustment following reproducible microscopy reporting principles. [2]

Samples and acquisition record

WL-MIC-01. HEK293 cells were imaged 44–48 h after transfection, before G418 selection. The team confirmed 2% PFA fixation followed by DAPI, with no permeabilization; equal exposure within each fluorescence channel across groups; and blank calibration. Identically numbered channels are the same field. The source provides 1–3 fields per condition and no independent biological repeat or live/dead stain.

The experimental date, operator, delivery method, objective, numeric exposure/gain and raw camera intensity conversion are not resolved by the supplied record. The image exports are 8-bit; the available scale bars are retained rather than replaced with an inferred pixel calibration. The undated provenance entry separates the supplied evidence from absent acquisition metadata. Culture and delivery specifications are on Experiments.

Audit thresholds with held-out blanks

The untransfected blank estimates image background for threshold setting. The Orco-only condition contains the green reporter module without the mCherry sensing cassette; it is a channel-specific negative control for RED. Neither is a viability control. The original blank was used both to fit and inspect the primary threshold, so its 1/170 positive-object fraction cannot establish specificity.

We therefore added a post-hoc leave-one-blank-field-out calculation: calibrate from the other two fields and evaluate the held field. All three splits are shown; no favorable split was selected. This checks within-batch field sensitivity, not independent-day assay specificity.

Statistical methods and assumptions

For each of the 11 nonblank conditions and each channel, construct the 2×2 table [[positive, eligible−positive], [blank-positive, blank-eligible−blank-positive]]. We compute one-sided Fisher exact values for the “greater” direction using SciPy. [3] Holm adjustment is performed separately over the 11 RED and 11 GREEN comparisons: sort raw values, multiply by the number of remaining hypotheses, take the cumulative maximum and cap at1. Absolute effect size is the condition fraction minus the blank fraction in percentage points.

These are conditional numerical diagnostics under an independent-object model. Objects from the same field share exposure, local density and preparation; multiple fields from one culture are pseudoreplicates for a biological treatment comparison. Moreover, the primary blank helped set the threshold. The nominal p values therefore do not establish biological significance, and the absence of a small p value is not evidence of equivalence. No number of object-level tests replaces an independent transfection.

The downloadable CSV also reports nominal 95% Wilson binomial intervals. For p=k/n and z=1.959964, the center is (p + z²/(2n))/(1 + z²/n) and half-width is z√[p(1−p)/n + z²/(4n²)]/(1 + z²/n). This describes counting uncertainty under the same independence assumption; it omits biological variation, segmentation error, threshold estimation and clustering. These intervals must not be relabeled as culture-level efficiency intervals.

Two percentages, different quantities

The object CSV reproduces all 12 condition counts and 72 threshold-sensitivity cells. Under the specified nominal model, eight of ten receptor-labelled RED comparisons fall below Holm 0.05; Or22a and Or98a do not. GREEN has two such comparisons, Orco-only and Or35a. The complete counts, effect sizes and numeric values are in Results, with no claim of a repeatable biological effect.

Pixel area and object positivity show no detectable monotonic agreement across the 12 labels: REDρ=0.19 and GREENρ=−0.09. The pixel-area statistic is a field median above a global threshold; the object statistic pools counts above local-background-subtracted thresholds. Neither can validate the other merely because both are percentages.

Or98a is the diagnostic case: 99.10% median GREEN area but 0.50% GREEN-positive objects. Its GREEN export clipping is only 0.0002%, with median intensity 39–45 DN. Thus broad elevation above blank, not demonstrated reporter saturation, is the supported observation. A bright background ring can reduce local contrast; testing that explanation requires inspection of signal and ring distributions, raw acquisition and reacquisition at lower density. DAPI clipping and unresolved aggregates are separate, documented problems.

P2: separate the trace from the correction

The acquired P2 pilot adds a different measurement to the endpoint images: one 96-well HEK293 plate recorded about 72 h after transfection, without G418 selection. Each condition × stimulus has one well. Fifteen repeated readings of a well describe its time course; they do not provide fifteen independent samples.

Each test excursion uses the maximum contiguous three-reading mean, divided by the same well’s five-reading F0b, minus one. The corrected metric then subtracts the earlier buffer excursion, which uses a different baseline. Consequently A11’s 11.86% test excursion and 21.48 percentage-point corrected difference answer different questions. H03 illustrates the importance of this distinction: subtracting a −30.08% earlier buffer excursion turns a 1.42% test excursion into a 31.50 percentage-point corrected difference.

All 32 original exports and 3,840 readings are preserved. The 24 corrected metrics in rows B/C are excluded following the source-reported gain mismatch; numeric gain itself remains unknown. The other 72 values are retained conditionally. Unknown VOC doses, incomplete DMSO vehicle matching, buffer-control excursions and the absence of independent repeats prevent a calibrated detection limit or receptor-specific response classification.

Selection is the main uncertainty

The dominant uncertainty is selection: eligible objects retain only 7.1–20.9% of segmented DAPI foreground in receptor conditions. That is a fraction of fluorescent area, not a fraction of cells. Dense regions remain visible in overlays; they cannot be assigned a reliable cell count from these two-dimensional exports. Segmentation has been visually inspected but has not been benchmarked against independently annotated nuclei.

The next validation set should contain an independently prepared blank, Orco-only and one OR condition; systematic fields spanning sparse and dense areas; raw camera data at documented exposures; and a suitable independent nucleus/viability measure. Blind annotation of sparse, dense and blank fields would permit precision/recall and merge/split-error assessment. A second transfection would begin to test reproducibility; extra images from the existing culture cannot do that.

The P2 pilot has now recorded baseline, buffer and nominal VUAA1 traces. The next functional measurement needs a matched vehicle, a reporter control such as ionomycin, recorded gains and independent repeats before interpreting VOC specificity. The time-course specification and platform diagnostic matrix explain which failure each control addresses.

Conclusion

The analysis provides an explicit denominator, reproducible calculations and inspectable failure modes. It measures reporter-associated contrast in a selected subset, reveals calibration sensitivity and separates bright field area from local fluorescence. It does not estimate transfection efficiency, biological reproducibility or receptor response.

Data and reproduction package

Download the complete control-audit package

The package contains six exact input files, the Python source, all output CSVs, PNG/SVG figures, a README, runtime versions and SHA-256 input hashes. Unzip, install NumPy, SciPy and Matplotlib in Python 3, then run python compare_controls.py. Paths resolve relative to the script, so the analysis does not require the wiki server or an online account.

Image segmentation can be reproduced separately from the primary analysis package and the unchanged TIFFs and source manifest. Run analyze_microscopy.py followed by analyze_nuclear_objects.py with the documented repository layout. The added control script verifies the exported counts before computing comparisons and never overwrites source images or primary tables.
