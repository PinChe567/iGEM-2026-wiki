Required metadata for every future evidentiary figure or table
  • Unique figure/table number and precise caption
  • Meaningful alt text or adjacent long description
  • Experiment/dataset ID
  • Units
  • n and whether replicates are biological or technical
  • Summary statistic / error representation
  • Statistical method and exact outcome when used
  • Preprocessing / normalization disclosure
  • Source and analysis-code link
  • Explicit note if a visual is illustrative rather than evidentiary

Never redraw, smooth, “clean,” or enhance evidentiary images with generative AI. Never hide excluded data or failed replicates.

Integration

What can and cannot yet be connected across Sense → Read → Decode → Act.

  • Sense. Current genetic architecture is specified on Design. No team-reviewed VOC / VUAA1 assay figure is published on this hub.
  • Read. V2 reader design files exist on Hardware. That is not a calibrated fluorescence instrument and not a biological measurement.
  • Decode. The computational pipeline is documented on Model. No public verified metrics table is published here.
  • Act. No closed-loop actuation or end-to-end Sense → Read → Decode → Act experiment is claimed.

Integration gap

No end-to-end AeroSense experiment linking living-cell sensing, portable optical acquisition, and model classification has been supplied with verified evidence. Biology, model, and hardware tracks remain separately scaffolded until a dated notebook entry and reviewed dataset close the loop.

Limitations and claims boundary

  • No AeroSense-measured biological, model, or hardware performance numbers are published on this page.
  • Proposal expected results (including accuracy, fluorescence-change, transfection, or detection goals) are not treated as outcomes.
  • Literature that motivates methods is cited on Design/Parts/Experiments; literature is not AeroSense results.
  • Integrated end-to-end sensing → optics → classification evidence is absent.
  • Hardware BOM/architecture conflicts remain unresolved on Hardware and are not papered over with results language.
  • This page will not host AI-redrawn gels, plots, or microscopy as evidence.
