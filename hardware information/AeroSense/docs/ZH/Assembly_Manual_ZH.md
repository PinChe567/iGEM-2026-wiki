# AeroSense 組裝手冊

用途：四個液體獨立、气路共用的平底井，靠近原PCB四顆LED，一顆PD收光。PCB名目100×90 mm；原板尚未製造。本手冊是一份完整的工程原型組裝流程，並未把名目CAD配合當成實板驗證。

![assembly_closed.png](../../results/images/assembly_closed.png)

先做順序：閱讀材料表 → 量測廠商板件資料 → 列印配合試片與乾式零件 → 不通電試裝 → 電子檢查 → 無細胞光學／氣路測試 → 材料與細胞驗證。任何步驟不合格，就停在該步，不用硬壓零件或靠normalize掩蓋問題。

STL/根目錄共8個工作件。OPTION_accessible_cap中兩件會替代04內蓋，使整機變9件；不是再把兩個蓋子疊上去。所有零件以mm輸出、無支撐，STL本身不攜帶單位。

# 1. 材料、工具與列印

| 零件 | 樹脂／數量 |
| 01一體主殼 | Rigid PC/GF-like Black ×1 |
| 02底座與PCB柱 | Aqua 8K Gray ×1 |
| 03鉸鏈外蓋 | Rigid PC/GF-like Black ×1 |
| 04氣路遮光內蓋 | Rigid PC/GF-like Black ×1 |
| 05四個平底well | Aqua Clear Plus ×4，NE/NW/SW/SE各1 |

Aqua Clear Plus為配合與材料試驗用，不是已驗證的HEK293T培養材。黑樹脂內蓋亦接觸樣本氣體，須測氣味吸附、殘留與背景。Gray底座若透外光，使用同一STL改印Black，不增加件數。

用Sonic Mighty Revo 16K與實際樹脂批號校正，不猜曝光秒數。先做0.15 mm單邊滑配、M3螺帽槽及0.5 mm底厚試片。大平面傾斜列印；井腔朝可排液方向，支撐避開液面接觸底、密封面及定位面。依原廠清洗、乾燥、固化流程，測固化後尺寸。未清除的液態樹脂不能封在內腔。

工具：游標卡尺、塞尺、M3/M4對應六角匙、鑷子、小剪刀、適當防護、萬用表、示波器／邏輯分析儀；軟矽膠片0.8 mm。完整數量與單價在獨立BOM工作簿。樹脂不可直接攻牙、硬敲或反覆彎折卡扣。

# 2. 座標、對位與送製前檢查

![optical_registration.png](../../results/images/optical_registration.png)

本圖採光學面朝上的組裝視角，D5封裝中心為(0,0)。LED中心名目(±3.3,±5.7)，液體井中心(±3.3,±2.65)。D1=SW、D2=SE、D3=NE、D4=NW是PDF讀圖的暫定對應；須確認BOTTOM圖是否鏡像，不能只看左右猜接線。

Vishay圖面光學中心距5 mm封裝底邊2.1 mm，因此沿長軸偏0.4 mm；方向取決於元件旋轉。模擬暫用(0,-0.4)，並掃描反向。四井仍依LED定位。實際die形狀沒有被完整提供，模擬3×2.5 mm僅是7.5 mm²等面積近似。

向廠商索取：含元件STEP、板厚、四孔座標與孔徑、底面电池座含電池高度、USB-C與SW1插拔包络、LED出光窗與PD旋轉。名目孔位±45/±40 mm、板厚1.6 mm不是廠商認證尺寸。

# 3. 風扇、PCB與底座

1. 斷電並移除電池。清除支撐、毛邊、粉屑，確認八件沒有翹曲或封閉樹脂囊。將M3螺帽放入對應捕捉槽，應平貼且不能突出裝配面。

2. 將40×40×10 mm風扇放在02底座，中心(0,-12)，四孔距32 mm。用4組M4×20螺絲／墊片／螺帽固定。氣流經底座吸入，流過PCB下方，再從電子艙開口排出。風扇不連通well氣路。

3. 確認風扇與固定件不碰板底元件：風扇本體上方允許23 mm元件高度，固定件上方僅16 mm，兩者都已預留2 mm名目間隙。電池座若進入較低區域，必須先改座位／高度，不能剪掉必要的PCB固定柱。

4. PCB光學面向上，放在四柱上。4顆M3×10螺絲配0.5 mm墊片固定，不壓電路、不使PCB彎曲。用塞尺確認板底避空。5. 接風扇5V與GND需廠商確認接點及供電餘量，不能把LED gate當供電。做好絕緣與拉力固定，再用另外4顆M3×10把主殼與底座固定。

6. 實板尚未到手，USB-C／SW1開口只能作名目試裝。應讓插頭外殼完全進出，開關全行程不摩擦，線材不掃到光學部件。請把實測尺寸填入validation/fit_measurements.csv。

# 4. 光學、井與密封

7. 將PD不透光軟圈定位於封裝上，名目外4×4、內3×3.4 mm，原厚0.8壓至0.6。不可碰bond／元件端子；偏心感光區到圈邊的裕量很小，必須向廠商確認window輪廓與旋轉，再測位置公差下遮擋比例。此尺寸不是已確認的光學密封規格。

8. 濾片最大5.2×4.2×1 mm，放入座內，Z41.1至42.1。只在乾區角落固定，不把膠伸入光孔。透明色片不等於合格發射濾片；需確認藍光完整波段阻擋與實際入射角下綠光透過率。

9. NE/NW/SW/SE各放入對應滑槽，讓凸緣落在Z56.8支承面。這是剛性卡匣滑入定位，不是彈性卡扣。四井外底Z42.5、內底Z43，均為平面，底厚0.5 mm；井腔4.7×3.4 mm。名目150 µL時液面Z52.387，理論滿杯約244.5 µL。先用無細胞液體量測實際容量。

10. 四孔井密封片外14×11.4 mm，孔中心(±3.3,±2.65)，每孔4.7×3.4 mm。0.8 mm片壓至0.6，由內蓋硬止擋限制壓缩。不要遮住井口，也不要讓密封片擠入液體。四井氣體共用，不宣稱氣相隔離。

# 5. 內蓋、氣路與可開闔外蓋

11. 一體04內蓋包含完整水平孔板：12孔、直徑1.6 mm、厚1.2 mm，板Z63至64.2。孔板上方由負X側進氣，管軸Z65.7；下方由正X側排氣，管軸Z61.5。兩端內徑2.4 mm，接尾外徑3.4、凸環4.0 mm。以2顆M3×10手轉螺絲鎖到硬止擋，不靠大扭力壓井。

一體內蓋上層難以目視清洗和固化，只作乾式／無細胞試驗。需要可接近的清洗面時，改用OPTION兩件內蓋：下件內建孔板，上件是屋頂，非對稱定位柱避免反放；增裁22×19、內孔15×12 mm密封圈。改2顆M3×12手轉螺絲；總工作列印件9。仍需材質與密封試驗。

12. 進、排氣各接一個疏水0.2 µm氣體濾器。外部供氣須可控流量與限壓。不要堵住排氣、把氣體直接打入液體，或用風扇抽取培養井。關內蓋前先停止供氣，保持排氣經濾器通大氣，緩慢落蓋並對角輕鎖；確認壓力回到零再供氣。

13. M3×75直桿穿過外蓋鉸鏈，加兩端墊片與尼龍防鬆螺帽，只限制滑出，不夾死轉軸。前端用1顆M3×12手轉螺絲閉合。外蓋故意不做氣密活塞；真正的氣路密封在well與內蓋。

# 6. 更換、初驗與故障排除

更換井：停止量測 → LEDs關閉 → 停供氣且確認無壓 → 打開外蓋 → 鬆兩顆內蓋螺絲 → 垂直提蓋並托住軟管 → 用凸緣提起各井 → 依實驗室流程處理液體 → 換井及清潔密封面 → 重新暗訊號、基線和標準品校正。不能在含液狀態翻轉整機。

| 現象 | 處理 |
| well卡住／PCB受力 | 量收縮、毛邊、凸緣及板上元件高度；不硬壓。 |
| ADC貼近0或滿刻度 | 查TIA、接線、外光和濾片；不可先normalize。 |
| 氣流低／壓力升高 | 停氣；查濾器濕潤、管折、堵孔、反接。 |
| 開關蓋後訊號跳動 | 查壓力脈衝、密封位移、外光及井定位重複性。 |
| 紫色透明井背景高 | 測光譜與空井自發螢光；拋光不能去除材料體吸收。 |

乾式驗收：無碰件、無彎板、螺帽全咬合、井可手動取放、開蓋不拉管、連接器可插拔。含液驗收：固定容量下靜置、傾斜與開蓋循環皆無液體接觸PCB，使用溫度下壓力與流量可重複。未完成這些記錄前，不把CAD渲染當成實物照片或成功證據。
