# 操作與驗證流程

本文件提供可執行的工程測試順序、資料欄位與暫定放行門檻。門檻是本專案的起始工程要求，不是公認GCaMP6f／HEK293T生物安全標準。先在測試計畫中登錄，失敗也保留原始資料。

| 階段 | 輸入／產物 |
| A 電子 | 電源、D1-D4頻率／電流、ADC波形、原始碼值 |
| B 空白光學 | 暗、空井、培養液、無GCaMP細胞、螢光標準 |
| C 氣路與機構 | 流量／壓差、漏液、關蓋壓力脈衝、20次更換 |
| D 細胞與標準品 | 細胞批次、密度、受體、參考刺激、存活與pH |
| E 分析 | 原始I/Q、校正矩陣、正規化、獨立批次驗證 |

每次記錄：操作者匿名代碼、日期、device ID、firmware與CAD檔案雜湊、樹脂批次及固化紀錄、井別與細胞批次、填充量、溫度、濕度、CO2／pH、標準氣體濃度與單位、流量、曝光duty、濾器／濾片型號。缺少單位的濃度資料不進模型訓練。

# A. PCB上電與四頻取樣

1. 由廠商先確認電源路徑、電池極性、SW1、3.3V數位／類比及2.5V參考。以限流電源開始，記錄空載、Wi-Fi、每顆LED和風扇的電壓／電流／溫升。風扇候選最大另需157 mA@5V（0.785 W）；不能假設原設計有此餘量。

2. 示波器看GPIO25/26/27/32及MOSFET drain；對應D1-D4。固定41/67/89/113 Hz，先低duty短時測試，量實際LED電流與光功率。Duty改變的是脈衝比例，不是恆流振幅。確認關機、停止、錯誤與重啟時全部關燈。

3. ADS8866：GPIO33 CONVST、18 SCLK、19 DOUT，DIN由硬體拉高。核對CONVST高至少8.8 µs後才讀；實作等待10 µs，SPI mode0、2 MHz、16位MSB first。以已知輸入確認零點、中量程與增益，VREF實測代入。不可直接把高電壓訊號接上ADC。

4. 每組2秒、4 kS/s共8000點。暫定：不漏點、無rail samples、取樣間隔最大誤差≤50 µs；不合格組標invalid。這個門檻不是準確度證明，須再量測同步串擾及振幅誤差。示波器確認程式時序後，才允許BOARD_VALIDATED=true。

5. 用稳定可控光源做至少5個強度、每級10組，量線性、暗噪聲、重复性与LED切換串擾。提議起始目標：中量程重複CV≤5%、擬合殘差≤5%；全量程不飽和。實際檢出限需由空白分布與低濃度重複實驗推定。

# B. 光學校正與紫色樹脂

同一批固化試片做0.5／1／2 mm厚度，測完整LED發射範圍與GCaMP發射範圍的穿透光譜，另量散射與空白螢光。使用空白參考與相同曝光，至少3件試片，報平均、標準差、厚度及儀器校正。Beer-Lambert可估體吸收，但表面反射和散射需分辨。

紫色可能來自吸收或染料／光引發劑，拋光只改善表面散射。若高背景或波段衰減隨批次、固化、浸泡時間改變，不能用單一倍率修正。快速路徑：先用透明井做無細胞光學空白；不合格則停止採用該樹脂作正式光窗，改用已驗證材料的光窗／培養容器，機構需重新配合。

光學串擾矩陣：固定LED與電子設定，每次只在一個井放同一穩定螢光標準，其他三井放匹配空白；記錄四頻複數I/Q，四個井各重複至少5次。所得M的列為LED頻率、欄為well，使用y=Mx+b。先扣除複數背景b，再求x；量測條件一致且矩陣條件數<30才嘗試反解。30是暫定工程門檻，需報誤差傳播。

GCaMP陰性細胞／培養液的同步訊號可來自漏藍光或樹脂，DLIA不會消除與LED同頻的背景。濾片須經實測入射角與光譜證明；採購OD規格不是本機漏光比例。

# C. 氣路、壓力與組裝穩定

在無細胞液體下測無孔板對照與選定孔板，建議掃0.25／0.5／1 mL/min。這是初始量測範圍，不是已證實細胞可耐受流量。兩端濾器、接管與內蓋需同時在位。記錄入口／出口流量、兩端壓差、關蓋瞬時壓力、質量變化及液面擾動。

孔板的孔速約Q/A_open；在定流量下減少開孔面積會增加孔速。模擬不含濾器，實際濾器可能主導壓降。閉蓋時若所有氣路堵死，ΔP約P_atm×ΔV/V：即使只壓縮1%氣體也約1 kPa，遠大於此模型約0.01 Pa的內艙流阻。保持過濾排氣暢通、低速閉蓋比「把所有地方封死」重要。

密封目標需依暴露規格制定：先量儀器本身流量誤差，再評估入口與出口差值；差值不能只用單一數值判斷漏氣，也可能是量測誤差或暫態。排氣濾器一旦濕潤、堵塞或壓力异常，立即停止。不能用這個殼當壓力容器。

組裝穩定試驗：同一空白或螢光標準，20次取放井／開關蓋，每次相同液量与設定，記錄四通道、漏液、定位、零件損壞与所需時間。先以訊號CV≤5%作起始目標，並與未拆裝的時間漂移對照分開。孔板不一定改善均匀度；必須報失敗結果。

# D. 細胞與參考刺激

使用HEK293T，並非細菌。培養、來源驗證、黴漿菌、廢棄及操作應遵循所在地實驗室對該細胞株的核准流程。外殼濾器與密封片不等於生物安全櫃，樹脂光學合格也不等於細胞相容。

先做材料浸出液與直接接觸對照：商用培養容器作基準，匹配细胞批次、密度、培養液、受體／GCaMP表達與觀察時間；至少3個獨立細胞批次。記錄形態、貼附、存活、pH、基線及參考刺激反應，不能只比較總亮度。

目前機構没有加熱、細胞溫度或CO2感測器。短時離開培養環境也可能改變pH與反應。記錄實際液體溫度、緩衝系統、CO2、濕度與蒸發；若需要持續培養，需外部環控或新增設計，風扇不能取代培養控制。

參考品優先選已確認能啟動該受體、穩定可取得、濃度可追溯的氣味標準；空白用同一載氣。濃度先由劑量反應實驗選在可重複且未飽和的範圍。鈣離子相關藥劑可檢查下游反應，但不等於受體對氣味的陽性對照；不可假定每次使用不影響後續細胞。此處不捏造尚未指定受體的通用濃度或藥劑配方。

建議每批：空白 → 基線 → 標準品 → 回復確認 → 隨機化樣本與空白 → 結尾標準品。若標準品造成不可逆漂移，改用獨立參考井／平行批次，而不是強制重複刺激同一井。四井共享氣體，不能把其中一井稱為「未暴露氣體對照」。

# E. Normalize、效能與模型驗證

儀器層先校正gain、phase和背景，生物層才算ΔF/F0=(F-F0)/F0。介面先逐頻率扣除複數暗訊號，再取振幅。基線F0與標準刺激各至少5個有效組；F0接近噪聲時拒絕除法。標準品正規化R=(F-F0)/(Fref-F0)，分母不足5倍暗訊號噪聲時不輸出R。

每個頻率的LED直接激發量可能不同，四井不能互相當成相同尺度。若沒有實測M，介面顯示的是LED通道正規化，不是假裝已解出獨立細胞井。校正不能補救飽和、非線性、材料光譜变化或受體失活。

效能測試至少包含：空白分布、反應時間與回復、量程／劑量反應、日內及跨日重複性、交叉氣味、濕度／溫度干擾、記憶效應與清洗、光漂白与光毒、裝配循環。以實驗批次為生物n；同一批的多個時間窗是技術重複。報原始資料、排除理由、平均與區間，不只挑漂亮曲線。

NN以cell batch／day／device分組切訓練與測試，不能把同一run的相鄰時間窗拆到兩邊。特徵正規化只用訓練集。交付的小型MLP可訓練和推論，但沒有實驗標籤資料，因此不附虛構氣味辨識模型或準確率。需留前瞻測試集，報混淆矩陣、各類召回、無反應／未知類及失敗模式。
