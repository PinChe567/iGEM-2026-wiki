其他意見：__________________________________________________________

觀察員另記：零件破損、錯方向、未壓到底、漏裝墊片、螺絲過緊、軟管拉扯、求助內容與時間。完成定義須事前固定：零件齊全、方向正確、井可取換、連接器可使用、無可見受力，不可只以「看起來組好了」判定。

分析：報參與人數與背景、任務完成率、時間中位數／IQR、求助和錯誤種類。Likert逐題報分布，不只報平均；N/A不算中立。先以5位新手做形成性試驗，不以此宣稱普遍可用性；改善後邀新參與者重測，避免只量到學習效應。

wiki呈現用可追溯的回饋→設計決策→新測試結果表。保留負面回饋，不捏造滿意度、使用者數或問卷結果。參與者引述匿名化後再公開。
