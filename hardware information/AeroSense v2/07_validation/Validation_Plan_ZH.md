# 無細胞螢光驗證程序

本程序使用 PBS 中的螢光素鈉，檢查已組裝的讀取器。本程序不驗證細胞存活或氣味辨識。

英文依 ASD-STE100 Issue 9 寫作原則編排。中文使用相同任務結構。文件保留完整操作與判讀條件；未宣稱正式詞彙符合性認證。

## 1. 準備實驗

1. 閱讀[開發者手冊](../04_manuals/Developer_Manual_ZH.md)。
2. 完成手冊中的電氣檢查。
3. 閱讀[使用者手冊](../04_manuals/User_Manual_ZH.md)。
4. 依[樣本指南](Fluorescence_and_Cell_Test_ZH.md)配製螢光素鈉。
5. 空白與兩個濃度使用同批 PBS。
6. 先導測試使用 C = 100 nM、0.5C = 50 nM。
7. 每井先採暫定 80 µL。
8. 在離開電路板的狀態下，確認此液量可蓋合且不漏液。
9. 若 80 µL 會溢流，將四井與全部對照的液量一起減少。
10. 正式系列使用相同的實際工作液量。

歷史模擬使用每井 100 µL。這不代表實物蓋合後可以容納該液量。螢光素強度受 pH 影響；不同溶劑會造成假的濃度差。[廠商說明](https://documents.thermofisher.com/TFS-Assets/LSG/manuals/mp36915.pdf)

細胞流程另見樣本指南。該流程使用現有 Gibco DMEM 與已表現 GCaMP6f 的 HEK293。本項 PBS 標準液實驗不使用 DMEM 作為稀釋液。

## 2. 完成實驗前檢查

1. 切斷電源。
2. 檢查 PCB 支撐與井組。
3. 確認組裝件沒有壓住元件。
4. 確認接頭仍可使用。
5. 手動轉動風扇。
6. 確認扇葉沒有碰殼。
7. 依開發者手冊完成電源與 ADC 參考電壓檢查。
8. 燒錄韌體與網頁檔案系統。
9. 將手機連接到裝置。
10. 選擇實機連線模式。
11. 保持全部 LED 關閉。
12. 取得一個原始 ADC 區塊。
13. 檢查 ADC 範圍與時序品質。
14. 若出現飽和、異常發熱或時序失敗，停止測試。
15. 排除故障後才繼續。
16. 電氣驗證完成後，由開發者解除 LED 鎖定。
17. 首次光學檢查使用低占空比。
18. 每次只開啟一顆 LED。
19. 確認每個通道對應的實際井位。
20. 測試停止控制。

J2 用於供電與充電。J3 是 3.3 V UART；接線依開發者手冊。軟體設定不等於實際時序量測。

## 3. 選定一組濾片配置

目前比較四組：無濾片、LEE 101 一層、LEE 101 兩層，以及 500 nm OD4 長通一層。

1. 初始原型先使用一層 LEE 101。
2. 將濾片裝在 PD 接收路徑上。
3. 封住濾片周圍可漏光的邊緣。
4. 先取得短時間空白與 C 的先導資料。
5. 檢查 ADC 是否飽和及是否有螢光響應。
6. 若訊號範圍不適合，在正式系列前調整設定。
7. 設定改變後，重收空白校正。
8. 若要比較另一種濾片，為該濾片取得完整的獨立系列。
9. 第一次濾片比較使用相同設定。
10. 若其中一組飽和，將該組標示為此設定下無效。

12.45 mm OD4 原片不能直接裝入目前的 5.2 × 4.2 mm 座。0.30 mm 厚度不能解決外徑不合。安裝檢查另見開發者手冊；本次沒有修改機構。

## 4. 維持相同測試條件

1. 每一正式系列使用同一井組與濾片。
2. 維持相同 LED 頻率與占空比。
3. 維持相同室內照明。
4. 若使用氣流，維持相同實測流量與幫浦位置。
5. 換液前停止排程。
6. 關閉 LED 與氣流。
7. 使用已確認不會讓液體碰到通電 PCB 的小體積換液方法。
8. 正式系列維持同次開機與相同光學定位。
9. 若必須重新開機或改變組裝，重做完整系列。
10. 不要合併不同開機或設定的半套資料。

初次接種、漏液檢查與大幅拆裝應在離板斷電狀態進行。讀取器沒有已驗證的自動換液機構。若無法安全換液，先改善組裝方式，再開始正式測試。

## 5. 取得正式量測序列

1. 每次量測前蓋好上蓋。
2. 先設定條件標籤，再取得該條件的資料。
3. 每個正式條件取得五個不同的有效 2 秒區塊。
4. 使用介面允許的區塊間隔。
5. 保留無效區塊及失敗標記。
6. 不要以平滑值取代原始值。

| 標籤 | 四井內容 | 動作 |
|---|---|---|
| DARK | 全部 PBS，LED 關閉 | 儲存暗訊號 QC 與原始 ADC。 |
| B_CAL | 全部 PBS，四 LED 開啟 | 取得五個亮燈空白校正區塊。固定此校正。 |
| PHASE_REF | 全部 C | 若使用即時相位顯示，另外取得五個相位參考區塊。 |
| B_CHECK | 全部重新加入同批 PBS | 取得五個獨立空白檢查區塊。 |
| NE_C | 只有 NE 為 C，其餘 PBS | 取得五個區塊。 |
| NW_C | 只有 NW 為 C，其餘 PBS | 取得五個區塊。 |
| SW_C | 只有 SW 為 C，其餘 PBS | 取得五個區塊。 |
| SE_C | 只有 SE 為 C，其餘 PBS | 取得五個區塊。 |
| ALL_HALF | 全部 0.5C | 取得五個區塊。 |
| ALL_C | 全部 C | 取得五個區塊。下一條件前儲存原始 ADC。 |
| ALL_HALF_REPEAT | 全部重新加入 0.5C | 取得五個區塊，檢查換液與時間效應。 |

正式序列共有 45 個區塊，不含 DARK。若使用 PHASE_REF，另外增加五個區塊。離線分析使用 ALL_C 作相位參考，不把 PHASE_REF 當作額外正式條件。

1. 完成 B_CAL 後，立即下載 B_CAL 的原始 ADC。
2. 在 PHASE_REF 或下一條件開始前完成下載。
3. 單井條件之間，依既定方法沖洗。
4. 若沖洗後仍有螢光，不要把該井當作乾淨空白。
5. 全部完成後，匯出完整 JSON。
6. 確認匯出檔含有全部條件標籤。
7. 將原始 ADC 下載檔與 JSON 一起保存。
8. 清除瀏覽器資料前，確認檔案可讀。

原始 ADC 匯出只包含最近一個區塊。完整 JSON 不會保存全部 ADC 波形。每筆資料保留其條件標籤與量測設定脈絡。

## 6. 分析資料

1. 在既有驗證資料夾安裝分析依賴。
2. 將範例 mapping 改成實際觀察到的 D1–D4 井位。
3. 以完整的匯出資料執行分析。

# 一次無細胞實驗：從四井螢光到手機結果

這是PCB到手後的主要驗證實驗，目標是用一次連續工作流程，檢查「讀到螢光、背景可校正、濃度反應合理、四井對應可辨識、資料能匯出」。預估熟悉操作後約60–120分鐘；首次燒錄與裝配另計。所有實測表目前空白。這個實驗不能單獨證明氣味辨識、細胞存活或氣體抵達細胞的時間。

## 先做10–15分鐘必要確認

1. 斷電試裝，確認不必硬壓PCB、插頭可插入、風扇不磨框。四井先離開PCB，以清水和紙巾看有無可見漏液，再擦乾。
2. 由熟悉電路的人按原理圖確認電源、3.3 V和ADC reference。J2 USB-C是供電／充電，J3才是3.3 V UART；按操作手冊完成韌體與網頁燒錄。
3. 先全關LED，取得有效原始ADC區塊。若讀值卡在上下軌、時序QC失敗或元件異常發熱，暫停；不能靠扣背景修好截波。確認供電與ADC後，才由負責人解除BOARD_VALIDATED鎖。
4. 無細胞、低duty短時間逐燈確認D1–D4對應哪個井，填入實際NE／NW／SW／SE對照。按一次手機停止，確認關燈。可借波形工具時順便看四個頻率；不能量到的時序項目留「未量測」。

以上不是另開一串研究實驗，而是避免後面的漂亮曲線其實來自接錯、飽和或方向錯誤。若10–15分鐘內發現故障，排除故障的時間不能跳過。

## 材料與固定條件

使用實驗室已有的穩定綠色螢光標準，例如合適的fluorescein標準液；空白、C與0.5C使用同一介質及pH。C代表本次選定的工作濃度，不是預先假造的GCaMP濃度或偵測極限。依標準液標籤／實驗室現有流程配製，記錄名稱、批號、實際濃度和pH。原廠資料指出fluorescein強度受pH影響，因此不能用不同pH的水做濃度比較。[原廠標準液文件](https://documents.thermofisher.com/TFS-Assets/LSG/manuals/mp36915.pdf)

四井每井100 µL、同一井組與濾片、固定全四燈duty和頻率、固定室內照明。先用一組C試讀：若截波或幾乎讀不到，可調整工作濃度／LED設定，之後重新開始完整空白與正式系列，保留試讀紀錄。正式系列開始後不再為了好看的曲線改設定。

不需為這次螢光試驗新增氣體感測器。若開啟供氣，量到的流量與泵位置要記錄，整組保持一致；它仍不能驗證CFD的濃度曲線。新的固定外殼供氣建議在Flow_Operation報告。

## 唯一實驗流程

每個狀態收5個不同、有效的2秒區塊；組間等待沿用UI允許值。每次改狀態，先停止排程，再換液、關蓋並填入下表的「條件標籤」。UI校正用的「條件代碼」則保持同一個裝配／設定識別，不因每個濃度標籤而改動。

| 標籤 | 放什麼 | 做什麼 |
|---|---|---|
| DARK | 四井空白，LED關閉 | 保存暗態及原始ADC；先確認QC。 |
| B_CAL | 四井空白，四LED開啟 | 收5組，作「亮燈空白」校正；之後凍結這組校正。 |
| B_CHECK | 相同空白，再量5組 | 獨立檢查背景；不加入校正集合，避免用自己扣自己。 |
| NE_C | 只有NE井為C，其他井空白 | 收5組四頻道原始I/Q。 |
| NW_C | 只有NW井為C，其他井空白 | 同上。 |
| SW_C | 只有SW井為C，其他井空白 | 同上。 |
| SE_C | 只有SE井為C，其他井空白 | 同上。 |
| ALL_HALF | 四井都是0.5C | 收5組，作濃度反應的中間點。 |
| ALL_C | 四井都是C | 收5組；可同時取得有效螢光相位參考。 |
| ALL_HALF_REPEAT | 再配／換回四井0.5C | 收5組，檢查換液及時間造成的差異。 |

換到下一個單井狀態前，依實驗室對該標準的洗滌流程清除前一井殘留；若樹脂明顯吸附、洗後仍發光，記錄並停止把它當成乾淨空白。不要把殘留訊號刪掉。移液器與現成耗材即可，不新增列印件。

每一組剛完成時，UI會保存當時的條件標籤與註記。最後匯出完整JSON；下載至少一組空白及一組C的原始ADC。確認匯出檔含以上標籤後，才清除瀏覽器資料。原始資料、錯誤／失敗區塊和校正記錄一併保留。

## 分析只看三張圖

1. **0、0.5C、C反應圖：** 使用原始I/Q，先扣獨立B_CAL的複數平均，再投影到本次ALL_C的實測相位。畫平均和技術區塊SD，保留未平滑值。半濃度應大致接近一半訊號，並檢查ALL_HALF_REPEAT漂移。

3. **獨立空白校正前後圖：** 用B_CHECK看穩定背景偏移是否減少。扣掉固定背景不會消除隨機雜訊；不能把平均歸零宣稱為SNR無限大。

## 開始前先固定的開發門檻

這些是本次原型的暫定工程門檻，不是iGEM規定或正式檢出限：所有正式區塊無截波且時序QC通過；每個通道的「0.5C平均投影−獨立B_CHECK平均投影」須大於B_CHECK區塊SD的5倍；訊號B_CHECK<0.5C<C；半／全濃度比介於0.35–0.65；兩個螢光等級的技術CV≤10%；重做0.5C的平均漂移≤10%；各LED最大反應來自預期井，列正規化對角項>0.60。全部投影已扣除一次B_CAL；檢出餘裕再與獨立空白平均相比，可避免空白整體漂移卻誤判通過。這不是把儲存的反應曲線再扣一次背景。

每項分開報告，不以一個總分掩蓋失敗。5個區塊是技術重複，不是5次獨立生物實驗。低訊號时CV不穩定，保留絕對SD與原始值；接近閾值時不能聲稱精確通過。若未通過，先依失敗種類檢查映射、背景漂移、濾片或飽和；不要用神經網路把失敗藏起來。

裝配與燒錄先完成；請2–3位沒參與設計的人照手冊裝配，記錄耗時、卡住處與協助，填既有問卷，修改最嚴重的1–2項後再試一次。這是使用者回饋循環，和上面的光學实验分開標示。
