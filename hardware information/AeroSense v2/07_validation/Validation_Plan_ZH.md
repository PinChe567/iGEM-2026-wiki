# 無細胞螢光驗證程序

本程序使用 PBS 中的螢光素鈉，檢查已組裝的讀取器。本程序不驗證細胞存活或氣味辨識。

英文依 ASD-STE100 Issue 9 寫作原則編排。中文使用相同任務結構。文件保留完整操作與判讀條件；未宣稱正式詞彙符合性認證。

## 1. 準備實驗

1. 閱讀[開發者手冊](../04_manuals/Developer_Manual_ZH.md)。
2. 完成手冊中的電氣檢查。
3. 閱讀[使用者手冊](../04_manuals/User_Manual_ZH.md)。
4. 依[樣本指南](Fluorescence_and_Cell_Test_ZH.md)配製螢光素鈉。
5. 空白與兩個濃度使用同批 PBS。
6. 先導測試使用 C = 100 nM、0.5C = 50 nM。
7. 每井先採暫定 80 µL。
8. 在離開電路板的狀態下，確認此液量可蓋合且不漏液。
9. 若 80 µL 會溢流，將四井與全部對照的液量一起減少。
10. 正式系列使用相同的實際工作液量。

歷史模擬使用每井 100 µL。這不代表實物蓋合後可以容納該液量。螢光素強度受 pH 影響；不同溶劑會造成假的濃度差。[廠商說明](https://documents.thermofisher.com/TFS-Assets/LSG/manuals/mp36915.pdf)

細胞流程另見樣本指南。該流程使用現有 Gibco DMEM 與已表現 GCaMP6f 的 HEK293。本項 PBS 標準液實驗不使用 DMEM 作為稀釋液。

## 2. 完成實驗前檢查

1. 切斷電源。
2. 檢查 PCB 支撐與井組。
3. 確認組裝件沒有壓住元件。
4. 確認接頭仍可使用。
5. 手動轉動風扇。
6. 確認扇葉沒有碰殼。
7. 依開發者手冊完成電源與 ADC 參考電壓檢查。
8. 燒錄韌體與網頁檔案系統。
9. 將手機連接到裝置。
10. 選擇實機連線模式。
11. 保持全部 LED 關閉。
12. 取得一個原始 ADC 區塊。
13. 檢查 ADC 範圍與時序品質。
14. 若出現飽和、異常發熱或時序失敗，停止測試。
15. 排除故障後才繼續。
16. 電氣驗證完成後，由開發者解除 LED 鎖定。
17. 首次光學檢查使用低占空比。
18. 每次只開啟一顆 LED。
19. 確認每個通道對應的實際井位。
20. 測試停止控制。

J2 用於供電與充電。J3 是 3.3 V UART；接線依開發者手冊。軟體設定不等於實際時序量測。

## 3. 選定一組濾片配置

目前比較四組：無濾片、LEE 101 一層、LEE 101 兩層，以及 500 nm OD4 長通一層。

1. 初始原型先使用一層 LEE 101。
2. 將濾片裝在 PD 接收路徑上。
3. 封住濾片周圍可漏光的邊緣。
4. 先取得短時間空白與 C 的先導資料。
5. 檢查 ADC 是否飽和及是否有螢光響應。
6. 若訊號範圍不適合，在正式系列前調整設定。
7. 設定改變後，重收空白校正。
8. 若要比較另一種濾片，為該濾片取得完整的獨立系列。
9. 第一次濾片比較使用相同設定。
10. 若其中一組飽和，將該組標示為此設定下無效。

12.45 mm OD4 原片不能直接裝入目前的 5.2 × 4.2 mm 座。0.30 mm 厚度不能解決外徑不合。安裝檢查另見開發者手冊；本次沒有修改機構。

## 4. 維持相同測試條件

1. 每一正式系列使用同一井組與濾片。
2. 維持相同 LED 頻率與占空比。
3. 維持相同室內照明。
4. 若使用氣流，維持相同實測流量與幫浦位置。
5. 換液前停止排程。
6. 關閉 LED 與氣流。
7. 使用已確認不會讓液體碰到通電 PCB 的小體積換液方法。
8. 正式系列維持同次開機與相同光學定位。
9. 若必須重新開機或改變組裝，重做完整系列。
10. 不要合併不同開機或設定的半套資料。

初次接種、漏液檢查與大幅拆裝應在離板斷電狀態進行。讀取器沒有已驗證的自動換液機構。若無法安全換液，先改善組裝方式，再開始正式測試。

## 5. 取得正式量測序列

1. 每次量測前蓋好上蓋。
2. 先設定條件標籤，再取得該條件的資料。
3. 每個正式條件取得五個不同的有效 2 秒區塊。
4. 使用介面允許的區塊間隔。
5. 保留無效區塊及失敗標記。
6. 不要以平滑值取代原始值。

| 標籤 | 四井內容 | 動作 |
|---|---|---|
| DARK | 全部 PBS，LED 關閉 | 儲存暗訊號 QC 與原始 ADC。 |
| B_CAL | 全部 PBS，四 LED 開啟 | 取得五個亮燈空白校正區塊。固定此校正。 |
| PHASE_REF | 全部 C | 若使用即時相位顯示，另外取得五個相位參考區塊。 |
| B_CHECK | 全部重新加入同批 PBS | 取得五個獨立空白檢查區塊。 |
| NE_C | 只有 NE 為 C，其餘 PBS | 取得五個區塊。 |
| NW_C | 只有 NW 為 C，其餘 PBS | 取得五個區塊。 |
| SW_C | 只有 SW 為 C，其餘 PBS | 取得五個區塊。 |
| SE_C | 只有 SE 為 C，其餘 PBS | 取得五個區塊。 |
| ALL_HALF | 全部 0.5C | 取得五個區塊。 |
| ALL_C | 全部 C | 取得五個區塊。下一條件前儲存原始 ADC。 |
| ALL_HALF_REPEAT | 全部重新加入 0.5C | 取得五個區塊，檢查換液與時間效應。 |

正式序列共有 45 個區塊，不含 DARK。若使用 PHASE_REF，另外增加五個區塊。離線分析使用 ALL_C 作相位參考，不把 PHASE_REF 當作額外正式條件。

1. 完成 B_CAL 後，立即下載 B_CAL 的原始 ADC。
2. 在 PHASE_REF 或下一條件開始前完成下載。
3. 單井條件之間，依既定方法沖洗。
4. 若沖洗後仍有螢光，不要把該井當作乾淨空白。
5. 全部完成後，匯出完整 JSON。
6. 確認匯出檔含有全部條件標籤。
7. 將原始 ADC 下載檔與 JSON 一起保存。
8. 清除瀏覽器資料前，確認檔案可讀。

原始 ADC 匯出只包含最近一個區塊。完整 JSON 不會保存全部 ADC 波形。每筆資料保留其條件標籤與量測設定脈絡。

## 6. 分析資料

1. 在既有驗證資料夾安裝分析依賴。
2. 將範例 mapping 改成實際觀察到的 D1–D4 井位。
3. 以完整的匯出資料執行分析。

```text
python -m pip install -r requirements.txt
python quick_check.py --input my_session.json --mapping SW,SE,NE,NW
```

上述 mapping 只是範例，不是已確認方向。分析器會拒絕 DEMO、重複資料，以及混用的設備或設定。分析器也會檢查硬體中繼資料、飽和與時序。每個正式條件需有五個有效區塊。若 ALL_C 的相位參考太弱，分析會停止。

分析沿用既有 measured-results 流程寫入結果。上述命令不會自行產生量測；self-test 只使用合成輸入。

| 輸出 | 判讀方法 |
|---|---|
| 空白、0.5C、C 響應 | 扣除 B_CAL 複數平均。投影到 ALL_C 相位。比較平均與區塊標準差。 |
| 四乘四單井矩陣 | 取各條件校正複數平均的幅值。對每個 LED 列正規化。檢查最大響應是否在預期井位。 |
| 獨立空白比較 | 以 B_CHECK 檢查固定背景是否移除。保留隨機雜訊與漂移。 |

矩陣不是帶正負號的相位投影矩陣。接近雜訊底時，幅值會有正偏差。矩陣不會自動分離各井細胞訊號。空白扣除不能消除散粒雜訊，也不能修復已飽和的波形。

## 7. 使用暫定驗收條件

以下是專案開發目標，不是正式檢出極限或生物驗收標準。

| 檢查 | 暫定目標 |
|---|---|
| 量測品質 | 全部正式區塊通過飽和與時序檢查。 |
| 偵測餘裕 | 每個通道的 0.5C 平均投影減去 B_CHECK 平均，超過 B_CHECK 區塊標準差的五倍。 |
| 濃度順序 | 響應由 B_CHECK、0.5C 到 C 逐步增加。 |
| 半濃度／全濃度比 | 比值為 0.35–0.65。 |
| 技術重複變異 | 兩個螢光濃度的 CV 均不超過 10%。 |
| 重複半濃度 | 平均漂移不超過 10%。 |
| 井位對應 | 每個 LED 列的最大響應在預期井位。列正規化對角值大於 0.60。 |

1. 分別報告每項結果。
2. 平均接近零時，保留絕對標準差。
3. 若任一項失敗，檢查飽和、井位、漂移及濾片漏光。
4. 修正原因後，才進入細胞量測。

偵測餘裕的空白平均扣除只用於該項判定。它不是再對保存曲線扣一次背景。五個區塊是技術重複，不是五個獨立生物實驗。

## 8. 正確描述結果

通過本試驗，可支持指定條件下的螢光偵測、手機控制、四頻量測與資料匯出。試驗也檢查背景校正與單井光學傳遞。

結果不直接證明 GCaMP6f 細胞反應、VOC 選擇性、細胞存活或氣體抵達時間。標準液亮度不等於細胞靈敏度。

1. 細胞量測依樣本指南操作。
2. 以同批細胞，比較本裝置與既有螢光讀取器。
3. 保留既有陰性與陽性對照。
4. 比較預先指定的 ΔF/F0 時間窗。
5. 不要任意平移曲線。

液體刺激與氣體刺激不自動等於相同劑量。共用氣相的四井不是四個獨立氣體暴露重複。

1. 可用性測試使用獨立空白問卷。
2. 請二至三位非設計者依手冊操作。
3. 記下所需協助與困難。
4. 修正主要問題後，再做第二輪。
