# Validation / 驗證

Start with Validation_Plan_ZH.md or Validation_Plan_EN.md: one cell-free reference-liquid experiment plus a short essential preflight. 從新版驗證計畫開始：一次無細胞標準液實驗，附必要的短檢查。

Use quick_check.py on the condition-labelled UI session JSON. Run --self-test to check software without producing experimental data. 輸入實測UI JSON才會生成結果；程式測試不生成實驗數據。

User_Feedback_ZH/EN describes the separate manual/usability review. Existing templates and plot_validation.py remain available for detailed engineering records; the shorter plan does not require completing all older forms. 問卷與手冊測試另列；保留的詳細記錄表不代表本次必須全部重做。

All measured-result templates remain empty until actual measurements are supplied. No simulation or DEMO is labelled as measured data.
