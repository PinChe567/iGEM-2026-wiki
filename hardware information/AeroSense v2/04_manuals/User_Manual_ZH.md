# AeroSense 使用者手冊

版本：2026-10-11。本手冊適用於已通過開發者檢查的裝置。細胞流程使用你現有的 GCaMP6f-HEK293 與 Gibco DMEM。

英文採 ASD-STE100 第 9 版寫作原則。中文採對應的短句、固定術語及單一步驟。文件未經完整詞彙與規則符合性審查，不宣稱正式符合 ASD-STE100。[寫作依據](https://www.asd-ste100.org/assets/files/ASD-STE100_ISSUE9.pdf)。

組裝及燒錄見[開發者手冊](Developer_Manual_ZH.pdf)。[樣本指南](../07_validation/Fluorescence_and_Cell_Test_ZH.pdf)提供詳細配方與來源。[BOM](../05_BOM/BOM_ZH.xlsx)及[調查表單](../07_validation/User_Feedback_ZH.pdf)各自獨立。

## 1 準備裝置

準備：取得已檢查的裝置、Wi-Fi 密碼及 API key。取得已確認的 duty、工作液量、濾片配置與實測 LED 方向。

| 術語 | 意義 |
|---|---|
| 工作液量 | 已量測且蓋合不漏液的液體量 |
| 區塊 / Block | 一次兩秒量測 |
| 亮燈空白 | 開啟 LED 的無細胞、無螢光樣本 |
| 相位參考 | 用來確認訊號相位的穩定螢光標準 |
| F0 | 光學校正後，未刺激活細胞的基線 |
| Condition ID | 同一組装配與量測設定的代碼 |
| 樣本標籤 | 本次量測內容，例如 B_CAL 或 ALL_C |

四井液體分開，但共用一個氣相及一顆 PD。顯示通道對應 LED 頻率，尚未自動分離成獨立井訊號。本機沒有已驗證的氣味分類器，也不控制溫度、CO2、濕度或氣流。

步驟：

1. 檢查裝置是否潮濕。
2. 檢查氣管是否被夾住。
3. 檢查可見線材是否鬆脫。
4. 確認工作液量已通過蓋合及漏液檢查。
5. 確認安裝的濾片配置。

確認：濾片試驗先用一層 LEE 101。實物約 100 µL 已近井口。80 µL 工作液量是暫定值，必須先通過實物檢查。各井與對照使用相同已確認液量。歷史模擬使用 100 µL。

異常處理：若漏液或接線鬆脫，不要通電。交由開發者處理。BOARD_VALIDATED 鎖定時，只能做暗場測試。

## 2 連接手機

準備：保持裝置乾燥。先找到實體 SW1。手機直連不需要網際網路。

步驟：

1. 開啟裝置電源。
2. 在手機加入 AeroSense Wi-Fi。
3. 輸入 Wi-Fi 密碼。
4. 若顯示沒有網際網路，保持連線。
5. 在瀏覽器開啟 http://192.168.4.1/。
6. 輸入提供的 API key。
7. 按「連線 / Connect」。
8. 確認頂端為「實機連線 / HARDWARE」。
9. 找到「停止／關燈 / Stop / LEDs off」。
10. 量測時保持網頁在前景。
11. 量測時保持手機不休眠。

確認：Wi-Fi 密碼與 API key 用途不同。「示範資料 / DEMO DATA」是合成練習資料。放入真實樣本不會使 DEMO 成為實測。

異常處理：若無法從網路停止裝置，用 SW1 斷電。重新連線不會自動找回未儲存的瀏覽器資料。

練習時，請開發者啟動 Demo。在該電腦開啟 http://127.0.0.1:8765/。[README.md](../README.md) 是文件索引，不是控制介面。

## 3 認識介面

使用右上角語言按鈕切換中英文。下表依現有介面順序排列。

| 區域 | 功能 | 檢查 |
|---|---|---|
| 模式與連線 | 模式、API key、連線錯誤 | 實測須為 HARDWARE |
| 量測排程 | 區塊數、間隔、duty、LED、開始與停止 | 開始前核對設定 |
| 品質與感測器 | ADC 及時序狀態 | valid 只涵蓋現有 QC |
| 四路頻率訊號 | 原始通道振幅與歷史圖 | 此圖未扣背景，也不使用 τ 平滑 |
| 實測背景校正 | 空白、相位參考、扣除及平滑 | 主動啟用背景扣除 |
| 校正與正規化 | Dark、Baseline、Reference、自動收集 | 活細胞 F0 另外取得 |
| 記錄與匯出 | 標籤、註記、JSON、CSV、raw ADC | 重整前先匯出 |

### 量測控制

| 控制 | 範圍或動作 | 初次用法 |
|---|---|---|
| Blocks | 1–60 個區塊 | 試讀一個；校正需五個不同有效區塊 |
| Interval | 每個兩秒區塊後等待 3–300 秒 | 設 3 秒時約每 5 秒一筆 |
| PWM duty | 1–50% | 使用開發者核准值；初期工程試讀為 5% |
| LED selector | Dark、單燈或 D1–D4 | 暗場須主動選 Dark |
| Start session | 啟動有限區塊排程 | 核對設定後才按 |
| Stop / LEDs off | 取消剩餘區塊 | 未完成區塊會捨棄 |
| Display smoothing τ | 0–120 秒 | 初始設 0；增加會延遲變化 |
| Condition ID | 組裝及設定識別 | 實體或設定變更後更換 |
| Current sample label | 標記新收到的資料 | 不修改舊資料標籤 |

D1 為 41 Hz。D2 為 67 Hz。D3 為 89 Hz。D4 為 113 Hz。用實測方向連結通道與井位。duty 不是校正後的光功率。

### 校正控制

| 控制 | 功能 |
|---|---|
| 1. 收集亮燈空白 | 啟動五個空白區塊 |
| 2. 收集螢光相位參考 | 啟動五個螢光標準區塊 |
| 3. 啟用實測背景扣除 | 扣除一次實測複數空白 |
| 清除背景校正 | 清除實測空白與相位校正 |
| 加入暗訊號／基線／標準刺激 | 加入最近一個符合條件的有效區塊 |
| 自動收集 | 收取後續有效區塊，至該階段共五個 |
| 清除校正 | 清除 Dark、Baseline、Reference 集合 |

自動收集需保持網頁開啟。先選階段，再開始量測。不可重複加入同一區塊。更新空白或相位參考後，舊 F0 與 Reference 失效。

Dark 用關燈資料檢查電路。亮燈空白已包含暗背景。啟用實測空白扣除後，不要再扣一次暗場。

Baseline 提供 F0。Reference 用於和已建立的標準刺激比較，不是氣味分類器。舊 Dark/Baseline/Reference 流程是另一條路徑。舊資料判讀見[詳細校正指南](../03_software/guides/Measured_Correction_ZH.md)。

### 品質與儲存限制

valid 代表現有點數、ADC 軌限及時序檢查通過。railSamples 是接近 ADC 極限的點數。maxIntervalErrorUs 描述與名義 250 µs 間隔的偏差。這些欄位不能證明生物結果有效。

電池電量、細胞溫度、風扇轉速及流量未量測。上方歷史圖永遠顯示原始振幅。τ 作用在校正顯示與處理值。原始及未平滑資料仍保留。

## 4 配製螢光標準液

準備：使用螢光素鈉，CAS 518-47-8。準備同批 1× PBS，pH 約 7.4。準備移液器、乾淨試管及避光材料。這是無細胞測試流程。

原液、稀釋液及空白均使用同一 PBS。不需要 DMSO 或乙醇。不可替換成 FITC、螢光筆墨水或成分不明染劑。不可將螢光素加入 reporter 細胞。

已有濃度明確的 1 mM 原液時，使用下表：

| 溶液 | 混合量 | 最終濃度 |
|---|---|---|
| 中間液 | 10 µL 原液＋990 µL PBS | 1.00 mL、10 µM |
| C | 50 µL 中間液＋4.950 mL PBS | 5.00 mL、100 nM |
| 0.5C | 2.50 mL C＋2.50 mL PBS | 5.00 mL、50 nM |
| 空白 | 相同 PBS，不加染劑 | 0 nM；至少 10 mL，另備清洗量 |

若只有粉末，先依瓶身身分及含量資訊計算。無水螢光素鈉 37.627 mg 定容至 10.00 mL，可得名義 10 mM。式量為 376.27 g/mol。取 100 µL 該原液加入 900 µL PBS，可得 1 mM。[樣本指南](../07_validation/Fluorescence_and_Cell_Test_ZH.pdf)說明純度及含水形式修正。

步驟：

1. 配製中間液。
2. 輕混中間液。
3. 用已混勻中間液配製 C。
4. 輕混 C。
5. 用 C 配製 0.5C。
6. 輕混 0.5C。
7. 保護試管，避免不必要照光。
8. 向各井加入相同已確認工作液量。

確認：濃度、PBS、pH、溫度及照光條件一致。工作液於當次新鮮配製。原液保存依瓶身說明。

異常處理：若原液身分或濃度不明，改用有紀錄的實驗室原液。不可直接秤單井所需的奈克量。訊號弱時，先檢查光路，再考慮改濃度。

## 5 選擇濾片配置

準備：請開發者安裝及確認濾片。先使用一層 LEE 101。每次比較維持相同 duty 及工作液量。

| 配置 | 用途 |
|---|---|
| 無濾片 | 工程漏光比較；ADC 截波即停止 |
| 一層 LEE 101 | 優先起始試驗 |
| 兩層 LEE 101 | 檢查額外抑制是否改善實測 SNR |
| 一層 500 nm 12.5 mm Ultra-Thin OD4 Longpass | 解決機構適配後的候選 |

LEE 101 裝在 PD 接收端。LED 激發路徑保持開放。加層同時減少藍光與綠色螢光。空白較低，不一定代表量測較好。

OD4 候選為 Everix 柔性 polymer/dye 濾片，型號 Edmund Optics #29-190。厚度 0.30 mm，直徑 12.45 ± 0.15 mm。它放不進現有 5.2 × 4.2 mm 座。原廠允許的固定或裁切方式及邊緣封光尚未解決。不可硬塞。也需確認入射角度下的透射光譜。

確認：選擇訊號足夠、雜訊可接受且沒有截波的配置。每次改濾片都重新校正。[濾片報告](../02_simulation/optics/README.md)提供數值比較及模型限制。

異常處理：若空白截波，停止量測。請開發者修正漏光或設定。空白扣除不能移除光子雜訊、截波或改變中的漏光。

## 6 校正日常介面

準備：固定井組、工作液量、濾片、duty、LED 及介質。亮燈空白需與樣本介質相同。另備穩定螢光標準。

### 收集亮燈空白

1. 輸入 Condition ID，例如 board01_wellA_80uL_LEE101x1。
2. 將匹配的無細胞空白放入四井。
3. 關閉遮光蓋。
4. 將樣本標籤設為 B_CAL。
5. 按「1. 收集亮燈空白」。
6. 等待五個不同有效區塊。
7. 確認校正狀態完成。
8. 下次量測前下載最近 raw ADC。

識別碼中的 80uL 僅在該液量通過實物檢查時使用。

### 收集相位參考

1. 換液前停止排程。
2. 確認 LED 關閉。
3. 停止外接氣流。
4. 在四井放入同一穩定螢光標準。
5. 關閉遮光蓋。
6. 將樣本標籤設為 PHASE_REF。
7. 按「2. 收集螢光相位參考」。
8. 等待五個有效區塊。
9. 檢查各通道參考狀態。
10. 勾選「3. 啟用實測背景扣除」。
11. 將 Display smoothing τ 設為 0。

### 檢查獨立空白

1. 換液前停止量測。
2. 將標準液換成匹配空白。
3. 關閉遮光蓋。
4. 將樣本標籤設為 B_CHECK。
5. 將 Blocks 設為 5。
6. 按 Start session。
7. 檢查五個新區塊。

確認：B_CHECK 是獨立檢查，不能加入 B_CAL。參考弱、空白不穩或 QC 錯誤時，不能可靠判讀。

異常處理：若檢查失敗，保留資料。修正原因後重做完整校正。不可用平滑隱藏失敗。

日常 PHASE_REF 校正和正式染劑系列用途不同。正式 quick_check.py 使用 ALL_C 定義相位，忽略額外 PHASE_REF。

## 7 執行正式染劑系列

準備：先完成開發者預檢。建立不溢出且維持同次開機及光學定位的換液方法。起始 C 為 100 nM，0.5C 為 50 nM。

| 順序 | 樣本標籤 | 內容 |
|---:|---|---|
| 1 | DARK | 四井空白；關燈 |
| 2 | B_CAL | 四井空白；亮燈 |
| 3 | B_CHECK | 四井空白；五個新區塊 |
| 4–7 | NE_C、NW_C、SW_C、SE_C | 僅指定井放 C；其他放空白 |
| 8 | ALL_HALF | 四井 0.5C |
| 9 | ALL_C | 四井 C |
| 10 | ALL_HALF_REPEAT | 四井新配 0.5C |

步驟：

1. 每個條件開始前設定樣本標籤。
2. 量測前關閉遮光蓋。
3. 每個正式亮燈條件取得五個不同有效區塊。
4. B_CAL 完成後立即保存最近 raw ADC。
5. ALL_C 完成後立即保存最近 raw ADC。
6. 每次換液前停止排程。
7. 確認 LED 關閉。
8. 停止外接氣流。
9. 使用已建立的清洗及換液方法。
10. 最後一個條件結束後匯出完整 session JSON。

確認：九個亮燈條件共 45 個有效區塊。DARK 另計。全系列設定不變。同一配置保持相同 Condition ID。不同溶液使用不同樣本標籤。

異常處理：若殘留使空白不乾淨，停止系列。若需要重開機或拆動光學組裝，之後重跑完整系列。不可拼接不同次開機的半套資料。

[驗證計畫](../07_validation/Validation_Plan_ZH.pdf)提供分析指令及門檻。螢光素鈉驗證的是光學量測，不能證明細胞靈敏度或氣味辨識。

## 8 配製完整 Gibco DMEM

準備：使用你現有已表達 GCaMP6f 的 HEK293。使用現有 Gibco DMEM，以及這批細胞已成功使用的 FBS。不需重新建立 reporter 表現程序。

50 mL 完整培養液步驟：

1. 閱讀 DMEM 瓶身標籤。
2. 確認它是基礎培養液或已配好的完整培養液。
3. 確認是否已有 L-glutamine 或 GlutaMAX。
4. 若已是完整培養液，直接使用，不再加 FBS。
5. 若是基礎 DMEM，取 45.00 mL 至無菌容器。
6. 加入 5.00 mL 現有合適 FBS。
7. 輕輕混合。
8. 標示最終 50.00 mL 為 DMEM＋10% FBS。

確認：若已有 L-glutamine 或 GlutaMAX，不要自動再加。若兩者皆無，依既有細胞流程及產品指示補充。補充液體積包含在最終 50 mL 內，需等量減少基礎 DMEM。

若既有流程要求額外 2 mM glutamine，可用 200 mM 原液 0.50 mL。配合 44.50 mL 基礎 DMEM 與 5.00 mL FBS，最終為 50.00 mL。此條件範例不是每款 Gibco DMEM 都要另加 2 mM。

保持 reporter 既有篩選條件。不可因其他配方有抗生素、丙酮酸或其他添加物就自行加入。除非既有流程要求，否則不另做 FBS 熱去活化。

環境步驟：

1. 將培養箱設為 37°C。
2. 使用這批細胞與此 DMEM 既有成功的 CO2 設定。
3. 若既有設定是 5%，保持濕潤的 5% CO2。
4. 平衡後檢查培養液 pH。

異常處理：若瓶身配方改變，先查產品說明，再改 CO2 或補充物。Gibco DMEM 配方不同，部分要求 5–10% CO2。首次裝置比較維持已成功的培養方式。不要求另外購買 EMEM。詳見[完整培養液指南](../07_validation/Fluorescence_and_Cell_Test_ZH.md)。

## 9 接種及確認可開始時間

準備：使用健康增殖中的細胞。在遠離電子零件處準備可拆井。使用與材料相容的合格無菌流程。保留同批標準培養器皿對照。

井底名義面積為 0.112 cm²。先用每井 3,000 個活細胞。若液量為 80 µL，懸液濃度為 3.75 × 10^4 活細胞/mL。這是起始估計，不是已驗證最佳值。

四井需 320 µL。為補足操作損耗，至少配 400 µL。若實測原液為 1.00 × 10^6 活細胞/mL，取 15 µL 加入 385 µL 完整 DMEM。可得 400 µL 目標濃度懸液。計算使用活細胞，不是所有顆粒。

若工作液量改變，使用 3,000 × 1,000 / 每井µL 數，計算每 mL 活細胞濃度。標準培養器皿依每 cm² 細胞數配對。

步驟：

1. 依實驗室既有解離程序取得細胞懸液。
2. 計算活細胞數。
3. 用完整 DMEM 稀釋至目標濃度。
4. 將可拆井平放在無菌外層培養皿。
5. 分裝前輕混細胞懸液。
6. 沿各井側壁緩慢加入 80 µL。
7. 檢查是否有氣泡。
8. 使用可適當氣體交換的外層培養皿蓋。
9. 依第 8 節環境培養。
10. 於 4–6 小時檢查貼附。
11. 於 18–24 小時檢查形態及覆蓋率。
12. 於 24–48 小時檢查健康及 reporter 回應。

80 µL 僅在工作液量測試通過後使用。不可將 PCB 或電池放進濕潤培養箱。若從冷凍管開始，先在標準器皿恢復培養。

確認：細胞健康且已貼附。沒有可見污染或明顯脫落。覆蓋率暫以 60–80% 為起點。已知陽性對照需在參考儀器上有反應。時間到了不等於合格。

本專案尚未證明 Aqua Clear Plus 的培養相容性流程。需和標準培養器皿比較。樣本指南提出存活至少為匹配對照 80% 的開發門檻，也列出背景及貼附檢查。

異常處理：若標準塑膠通過但樹脂失敗，先解決材料或表面流程。不可假定多等固定時數就能改善貼附。UV、酒精或塗層本身不能證明相容。

用匹配的無細胞井檢查蒸發。損失超過起始體積 10% 是暫定重做門檻。80 µL 的 10% 為 8 µL。不可盲目補液後視為條件未變。

## 10 校正並量測 reporter 細胞

準備：優先沿用已建立的 assay 介質。能維持必要環境時，現有 DMEM 是第一條路徑。維持其 CO2 條件，並實測樣本為 37°C。本機不提供這些環境控制。

PBS 染劑液不是細胞生長培養液。HEPES 不能控制溫度。樣本指南的替代量測緩衝液是選項，不是必買品。

光學準備步驟：

1. 用實際 assay 介質準備無細胞空白。
2. 使用最終濾片、duty、工作液量及光學配置。
3. 依第 6 節收集亮燈空白。
4. 依第 6 節收集匹配相位參考。
5. 檢查獨立空白。
6. 依已建立的校正轉移方法裝入細胞樣本。

確認：不同井可能改變樹脂背景及定位。先在無細胞試驗檢查重複換井。不可保留同一 Condition ID 掩蓋組裝變更。重開機後需有效校正轉移程序及新的 F0。

細胞量測步驟：

1. 確認樣本溫度及介質 pH。
2. 量測前檢查細胞貼附。
3. 設定未刺激細胞的樣本標籤。
4. 選擇 Automatic capture Baseline。
5. 開始未刺激狀態量測。
6. 取得至少五個不同有效基線區塊。
7. 若 assay 允許，保留穩定的 2–5 分鐘基線。
8. 記錄刺激開始時間。
9. 執行實驗室既有刺激流程。
10. 用相同設定收集回應。
11. 匯出原始及未平滑校正資料。
12. 量測後檢查貼附。

確認：細胞已表達 GCaMP6f。已知陽性對照仍需確認 reporter 回應可用。包含匹配 vehicle 及參考儀器對照。已有無 reporter 對照時一併使用。

第一輪以 10–15 分鐘量測作可行性試驗。這是規劃時間，不是已證明安全的暴露時間。初次光學／細胞比較保持氣泵關閉。不要將螢光素加入細胞。

異常處理：若溫度、pH、貼附或 QC 失敗，停止判讀。F0 近零或低於雜訊時，不強算比值。若環境控制尚未建立，先繼續無細胞測試。

獨立空白只扣一次，再以活細胞基線計算 ΔF/F0。不可把活細胞存成光學空白。PBS 空白不能代替實際培養液空白。

每個區塊平均兩秒，之後至少空檔三秒。快速 GCaMP6f 峰值可能被漏掉。使用預先選定時間窗比較已建立的持續回應。以記錄的刺激時間對齊，不移動曲線改善吻合。

共用氣相的四井不是四次獨立暴露。氣體抵達液面不代表抵達細胞。一般鈣離子陽性反應不代表氣味專一性。

## 11 匯出資料並結束

準備：匯出完成前保持瀏覽器開啟。JSON 保留較完整資料。CSV 方便檢視。

步驟：

1. 在註記欄輸入樣本及條件資訊。
2. 按 Export JSON。
3. 按 Export CSV。
4. 確認兩個檔案已儲存。
5. 若需要原始波形，下個區塊前下載最近 raw ADC。
6. 按 Stop / LEDs off。
7. 確認 LED 已關閉。
8. 停止外接氣流。
9. 保持出口開放至壓力平衡。
10. 拆卸或清潔前關閉電源。

確認：保存校正、原始值、失敗區塊及排除原因。檔名可包含日期、裝置、樣本、條件及重複編號。不能只留截圖。

裝置只留最近 raw ADC 區塊。RAM 上傳佇列可留八筆摘要。重開機會遺失待傳摘要。瀏覽器最多留 1,000 個已收到區塊。重整或關閉前先匯出。

異常處理：若匯出不完整，保持網頁開啟。先解決下載問題，再清除紀錄。不可將找回的部分資料稱為完整系列。

## 12 排除問題

| 現象 | 動作 |
|---|---|
| 網頁 404 | 請開發者檢查 LittleFS 上傳 |
| 401 | 確認本裝置 API key |
| board_not_validated | 保持 Dark；請開發者檢查 |
| ADC_rail、timing 或 jitter | 停止；保留 raw ADC 供診斷 |
| 空白很大或截波 | 檢查遮光、濾片旁路及 duty 後才重校正 |
| 相位參考弱 | 檢查標準液、定位及空白 |
| baseline_below_noise | 檢查 F0 及 reporter 回應；不強算比值 |
| 網路失效而無法停止 | 用 SW1 斷電 |
| 漏液或異常發熱 | 斷電並停止氣流 |
| 細胞脫落或 pH 改變 | 停止細胞測試，恢復既有培養環境 |
