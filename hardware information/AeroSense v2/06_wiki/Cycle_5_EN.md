# Engineering Cycle 5 · Can another person assemble it?

**Study designed; user testing not yet run**

## Design

Question: can a person who did not design the device assemble it, replace a well and identify a valid measurement using the manual? Freeze the manual and hardware version before testing; recruit a small practical sample and disclose its size and experience.

## Study materials

Prepare the labeled parts, bilingual illustrated manual, task sheet, observer log and feedback form. Explain consent and that the manual is being evaluated. Keep a safe cell-free setup and the same starting conditions for each participant.

## Planned test — not yet run

Observe locating parts, assembly, checking seals, connecting the phone, recognizing demo/live mode, running a blank and replacing a well. Record completion, time, requests for help and errors. Ask for clarity ratings and the exact confusing step. The supplied form contains no completed responses.

## Reserved for observed findings

Populate this section only after testing: participant count, tasks completed, median time, error categories, quotations with consent and limitations. Do not invent usability scores or describe project-owner feedback as independent user validation.

## Planned response to feedback

Link every recurring problem to a concrete manual figure, label or assembly change; preserve before/after examples. Plan two retests after revision. Include a new participant if available; if the same person repeats, report the learning effect. Report unresolved problems as well as improvements.
