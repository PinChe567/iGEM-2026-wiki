# Description：各部分證據如何連在一起

<a id="aerosense-system-scope"></a>
## 從氣體樣本到可解讀的訊號

AeroSense 探索工程化嗅覺受器能否用於小型生物氣味量測平台。預定路徑為：氣體樣本 → 共用氣室 → 液體／細胞介面 → OR／Orco 相關鈣離子反應 → GCaMP 螢光 → 光學讀取器 → 手機輔助分析。每個箭頭都是需要獨立確認的介面；某一階段計算或實驗成功，不等於整條鏈已驗證。

讀取器使用四個 LED 激發與一顆共享 PD。不同頻率協助分離激發通道，而不同井的貢獻仍需要光學校正。CAD、firmware、操作介面與可重現物理模擬已提供；目前 PCB／外殼尚未完成實體驗證。[Hardware](Hardware_Sections_ZH.md#hardware-status)說明裝置與下一階段少量關鍵測試。

<a id="aerosense-model-scope"></a>
## 模型決定下一步該測什麼

光學模型評估光源 → 假設細胞層 → PD 的路徑；氣體模型評估到氣液介面的傳輸，並在不改指定 CAD 的前提下比較操作流量。捕捉／吸收蛋白在身分、結合行為及傳輸效果確定前，仍是獨立假說。這些模型支持工程決策，但尚未建立快速生物反應的證據。

仿果蠅解碼器是另一條工作線。目前已報告的基準使用公開金屬氧化物感測器資料，不是 AeroSense 量到的螢光。要宣稱整合式氣味分類器，還需要實測受器反應資料、獨立驗證切分及完整訓練紀錄。[Model](Model_Sections_ZH.md#physical-models)將這些證據類型及假設分開說明。

<a id="aerosense-current-boundary"></a>
## 目前主張與下一步

目前貢獻是可檢查的候選讀取器，以及可重現地找出設計假設可能失效的方法。接下來聚焦實際試配與電路、blank／參考及井間混合、氣體傳輸量測，以及由另一人依手冊組裝。尚不宣稱已驗證的現場儀器、食品安全判定、無菌可重用細胞匣或實測偵測極限。完整支援檔案放附錄，關鍵證據與限制仍留在 Hardware／Model 主頁。
