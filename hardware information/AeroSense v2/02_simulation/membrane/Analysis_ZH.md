# 分子傳遞與PDMS薄膜評估

本節是**一維質傳篩選模型**，與三維氣流CFD、生物反應分開。使用者已確認HEK293T貼附在井底，每井100 µL。4 × 2.8 mm截面形成8.929 mm液柱，井口下方氣相高度3.571 mm。本計算不等於實測細胞暴露量、存活率、受體反應或GCaMP反應時間。

## 本次工作版的決策

保留目前八件機構作為實驗載具，**暫不把PDMS放入指定組装或必要採購BOM**。目標VOC、干擾物與薄膜／培養液質傳資料尚未確認。這也不代表既有井已通過快速氣體到細胞的驗證：深液柱是必須先量測的疑點。以下膜厚是研究掃描參數，不是另外一組列印選項。

PDMS可在持續濃度差下產生選擇性透過，但不是只讓「目標VOC」通過的通用閘門。若某物質可穿膜、下游封閉且沒有消耗，它最後仍會趨近平衡；本模型的最終下游氣相等效濃度與上游相同。薄膜選擇性主要改變到達速度、暫態組成與滯留，不等於平衡時永久排除該分子。因此需先定義目標、干擾物、濕度、容許延遲及回復要求。

## 文獻支持哪些判斷

- 疏水性描述液態水的潤濕行為，不等於阻擋水蒸氣。Bian等人的8–160 µm交聯PDMS薄膜仍有水蒸氣傳遞；最薄膜也顯示表面動力學可能使簡單的厚度反比失效。該材料不能直接當成你將使用的配方。[原始研究](https://onlinelibrary.wiley.com/doi/10.1002/marc.202000682)
- Heo等人實測PDMS中的蒸發與培養液滲透壓變化，包含加濕培養環境。其裝置及細胞不同於AeroSense；這支持必須查水分流失，不能據此直接預測本裝置細胞存活。[原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC2605290/)
- PDMS可透過氧與二氧化碳。Firpo等人於293 K報告氧滲透率2.8 × 10⁻¹³ mol m⁻¹ s⁻¹ Pa⁻¹及擴散係數3.1 × 10⁻⁹ m²/s，也量測了表面阻力。這些是參考材料的數值，不是本次膜的量測。[原始研究Table 1](https://www.mdpi.com/2073-4360/11/5/910)
- 小分子會分配進PDMS；某些溶劑亦造成膨潤。滯留再脫附會改變樣本脈衝或造成殘留，程度依分子及條件而變。[Toepke與Beebe](https://pubmed.ncbi.nlm.nih.gov/17203151/)、[Lee等人](https://pubmed.ncbi.nlm.nih.gov/14640726/)
- Lue等人研究兩種交聯配方的甲苯／氮混合氣，顯示濃度相關的傳輸。這不提供可通用到5:1、10:1、20:1的映射；本包不替這些配比捏造D、K、透過率或最佳值。[原始研究](https://www.sciencedirect.com/science/article/pii/S0376738809008783)

## 方程與邊界條件

各層實際濃度c = K u，其中u為氣相等效濃度，K = c層/c氣為平衡時的濃度比，分子與分母均用mol/m³。氣體K = 1。方程為K ∂u/∂t = ∂(D K ∂u/∂x)/∂x。相鄰有限體積格使用兩側半格阻力相加，介面通量守恆。額外表面阻力在PDMS两面各加入1/h，h以氣相等效濃度定義，單位m/s。

順序是井口PDMS（或無膜）、氣相空間、液柱；側壁不透過，底部零通量。底部只是觀察濃度的位置，不消耗VOC。初始濃度零，上游跳至1。輸出為c液/(K液 c氣輸入)，不是GCaMP強度。假設瞬間介面分配平衡、稀溶液線性吸收、固定D與K、均勻截面、無液相對流、結合、反應或細胞消耗；未含彎月面、膜撓曲、漏氣與繞膜旁通。

預設上游階躍直接施加在井口上方，省略管路、濾器及氣腔換氣，因此對到達延遲而言較有利。另用理想混合0.8544 mL氣腔、總流量0.1／1／10 mL/min做有限供氣敏感度，四井同時吸收。體積取氣腔矩形減導流台，未含管口；這是降階模型，不是CFD流場。`couple_gas_history.py`可讀實測或CFD井口濃度歷史，但只單向指定，不會把膜／液體吸收回饋給氣流。

有限體積系統轉成對稱矩陣後以矩陣指數推進，階躍輸入沒有時間步長截斷誤差。最下方液體格近似井底值，另做空間細化。`forced()`可對分段線性的井口歷史作時間上的解析積分。計算採SI單位，圖中的小時及µm由秒、公尺換算。

## 哪些是已知，哪些只是假設

| 參數 | 掃描值 | 證據性質 |
|---|---|---|
| 井截面／工作液量 |11.2 mm²／100 µL |現有幾何與使用者確認 |
| PDMS厚度 |25、50、100、250、500 µm及無膜 |研究網格，尚未選膜 |
| VOC在PDMS中的D |10⁻¹²至10⁻⁹ m²/s，十倍間距 |寬範圍敏感度，未指派分子 |
| PDMS／氣相K |1、10、100、1000 |假設濃度比 |
| 液體／氣相K |0.1、10、1000 |假設，非已知Henry常數 |
| 液相分子D |0.5、1、2 × 10⁻⁹ m²/s |示例敏感度，不是目標VOC量測 |
| 氣相D |10⁻⁵ m²/s |假設；一維氣層對流速度設零 |
| 液相有效D倍數 |1、10、100 |混合敏感度代理，不是已求解攪拌流場 |
| 表面h |理想介面或10⁻⁶至10⁻³ m/s |未知界面動力學的敏感度 |
| 最長時間 |7日 |數值截尾範圍，不是可容許培養時間 |

一般VOC網格是等溫、未指定物種的研究，沒有擬合溫度公式；D、K是獨立假設輸入。換溫度需換成對應實測物性。只有氧範例明確引用293 K數據。水分流失速率沒有計算：缺PDMS–水分配／透過率、相對濕度、溫度及外部傳質阻力，不能填入假的每日失水量。

## 主要結果如何看

在液面濃度瞬間固定、液體靜止、不反應、底部不透過的條件下，解析解為t10 = 0.130159 L²/D、t50 = 0.378748 L²/D、t90 = 1.031105 L²/D。它們代表井底濃度到達平衡值10%、50%、90%，不是受體或GCaMP反應時間。

| 假設液相D（m²/s） |t10 |t50 |t90 |
|---|---:|---:|---:|
|0.5 × 10⁻⁹ |5.76 h |16.77 h |45.67 h |
|1 × 10⁻⁹ |2.88 h |8.39 h |22.83 h |
|2 × 10⁻⁹ |1.44 h |4.19 h |11.42 h |

這是**條件式但重要的傳遞瓶頸**，不能寫成「實機一定要23小時」。真正對流、混合、結合及分子溶解度都可能改變到達；井上方風變快也不等於8.93 mm液柱已混勻。相同解析模型中，3.571 mm氣層、D = 10⁻⁵ m²/s即使速度為零，t90仍約1.315秒：氣流示蹤點不動，不表示VOC分子停止擴散。

固定截面及D時，液相扩散時間與液量平方成正比。25 µL的反事實情境在D = 10⁻⁹時t90約1.43小時；這不是核准改液量或改CAD。100 µL下把有效D提高100倍，無膜篩選t90約0.25小時；加上名目100 µm膜後約0.85小時。當液相傳遞加快，膜本身反而可能成為主要阻力。

完整網格243組（含三組無膜基線）中，74組在7日內未達t90，CSV留空，圖標`>168 h`；不可填成零。D液 = 10⁻⁹、K液 = 10、100 µL代表例：無膜t90約22.85小時；100 µm膜、假設D膜 = 10⁻¹⁰及K膜 = 100時約23.39小時；再含1 mL/min有限供氣氣腔則約23.55小時。這些是敏感度結果，不是選出一款最佳市售PDMS。

以濃度定義的滲透率P_c = DK，單位m²/s；膜滲透導度DK/L，單位m/s。以分壓定義的P_p = DK/(RT)，單位mol m⁻¹ s⁻¹ Pa⁻¹，不能把兩者數值直接互換。持續梯度下的固有A/B通量選擇比是(D_AK_A)/(D_BK_B)。在此體相模型中，改厚度會同時改兩物種導度，不會單靠厚度改變固有選擇比；表面動力學、混合物吸收及膨潤則可能破壞此簡式。

L²/(6D)的膜時間延遲不等於井底t90。100 µm、D = 10⁻¹⁰時膜體相延遲只有16.67秒，但液柱仍慢。20分鐘输入脈衝也可在停氣後才形成寬廣的井底峰；無膜例約3.92小時達峰、峰值約输入平衡參考的2.78%。儲存／脈衝圖只描述可逆擴散記憶，未包含不可逆吸附與受體適應。K提高會同時增加儲存與導度，不能一概說K越大就越慢。

## 實際執行的CFD單向串接

`integrate_airflow.py`將選定擋板案例的NE井口歷史（Q=1 mL/min、假設氣相D=10 mm²/s）接到100 µL的無膜與100 µm示例。原始CFD只計算到300秒，井口t50=48.78秒、t90=149.02秒；取樣面Z=55.329 mm，作為名目井口Z=55.5 mm的近似。兩個示例在300秒的井底比例都低於10⁻¹⁰數值呈報下限。原始數值的極小正負值是浮點抵消誤差，不是物理負濃度，也不是已驗證的偵測極限。

為比較長時間尺度，300秒後另設兩個明示假設：井口立刻達到1，或永久維持CFD最後值0.991144。只有未來井口濃度一直介於兩值之間時，它們才構成上下界。以原入口濃度為參考，無膜t90為22.87–23.62小時，名目薄膜為23.41–24.18小時。立刻達1的延伸比各自理想井口階躍多約67.3秒；維持最後值的較大差異也包含邊界濃度永久降低的作用，不能全部解釋為氣路延遲。這裡沒有執行或暗示23小時的CFD。

串接保有1D指定邊界模型的守恆，但不是氣相－膜－液相雙向耦合的整機質量守恆模擬。上游CFD的液面不可穿透，加入液體或PDMS吸收後沒有回算氣相。這個例子顯示假設的深靜止液柱仍控制時間尺度，不能證明實際細胞暴露或整機質量平衡。來源雜湊、假設、原始時段與延伸情境分開保存於`results/CFD_rim_coupling_summary.json`及對應CSV。

## 氧、二氧化碳與水

氧範例是靜態、穩態傳質容量上限。採293 K文獻PDMS P／D、假設液相D = 2 × 10⁻⁹ m²/s、液面溶氧0.30 mol/m³及氣相氧分壓21,278 Pa。100 µL時，若井底濃度已降至零，最多約0.75 pmol/s/井；100 µm膜影響不大，因本例液柱阻力主導。0.01–5 pmol/s耗氧只是負載掃描，不是HEK293T實測耗氧或細胞數。負載超出上限時，固定耗氧穩態解不成立，不把負濃度當物理結果。

這沒有證明供氧安全、CO2／pH平衡或37°C培養成立。培養液、氣體組成、細胞數、耗氧、混合及目標溶氧仍須量測。PDMS疏水也仍可透水蒸氣；本包不把它認定為保濕膜、無菌屏障、已驗證耐壓密封或可靠的目標VOC過濾器。

## 數值檢查與最短下一步

128格單膜模型與L²/(6D)誤差0.00305%；液柱t90對解析解誤差0.000762%。代表性耦合模型從48格增加到96格，t90變化0.00405%。全膜掃描最差歸一化質量守恆殘差約2.17 × 10⁻⁵，取樣濃度在數值容差內保持[0,1]。這驗證程式如何解假設模型，不是驗證假設必然適合實機。詳細資料在`results/validation.json`、`membrane_sweep.csv`及`summary.json`。

加膜前先定義一種目標VOC、一種重要干擾物、氣相濃度與單位、濕度、溫度、配方及可接受延遲／回復；以空白記錄表填入實測膜厚及條件。以獨立濃度檢測比較無膜與有膜，GCaMP單獨無法區分質傳、受體敏感度及光學效應。優先確認真正100 µL井的底部到達行為。已知擴散性的無細胞示蹤物可查液體混合，但換分子不能證明目標VOC的分配或選擇性。這是有限的優先順序，不是要求把整個大型模擬網格都做實驗。

在取得資料前保留機構。若實際底部暴露無法快速建立，再考慮液路重設或經驗證的混合，之後才能宣稱快速生物感測。單加PDMS而不處理深液柱問題，沒有得到本結果支持。
