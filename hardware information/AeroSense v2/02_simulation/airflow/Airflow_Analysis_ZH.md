# 氣流設計分析

## 結論與列印幾何

採用「入口下方寬導流台階」，case `shelf_w8_e0p2`，整合在氣蓋左側壁，台階本身不增加列印件或螺絲；確保井口密封壓縮所需的可拆壓板另計於八件操作列印件。這是兼顧流向、可清洗與低零件數的原型候選，不能稱為全域最佳或已證實保護細胞。

導流台階實體座標：X = −7.4 至 −0.2 mm；Y = −4 至 +4 mm；Z = 58.2 至 59.4 mm。共同氣室 X ±7.4、Y ±6.0、Z 57.3–62.5 mm。進出氣口內徑2.4 mm，中心 Y=0、Z=60.8 mm，末端 X=±18 mm。局部氣蓋頂厚1.5 mm至Z64，外層上蓋板另延伸至Z66；CFD內頂仍為Z62.5。壓板實體Z56.1–57.3，四個4×2.8 mm孔；上方周邊密封片Z57.3–57.9，中央氣體仍從57.3開始，蓋體下緣57.9。壓板可拆洗，因此操作件數增為八件。四井中心(±3.3,±2.65)，液體截面4.0×2.8 mm，內底Z43，井頂55.5；100 µL液面Z51.9286 mm。氣體共同、液體分開。

## 為何不選直立擋板

真正目標是避開朝向液面的集中氣流，並非製造亂流。1 mL/min時入口Re約0.589，本模型屬低Re層流；重新轉向不等於湍流。18個實際CFD幾何包含無擋板、12孔板、9個直立牆、3個L形罩、4個水平台階。直立牆阻擋水平入口後，把部分流量轉向下方，最差井口向下動量反而增加。L形罩也未優於無擋板。寬而較長的水平台階在三個網格皆降低此方向性指標，而且無封閉上層暗腔。

## 結果及代價

所有數值指氣體，不是培養液內細胞的剪力。井口下方1 mm的最差井向下動量代理值為 ρ Σ max(−uz,0)² ΔA；近液面速度P95取液面上0.6–1.4 mm的氣體。相對無擋板，台階的動量指標在0.4、0.3、0.2 mm網格分別降低30.9%、30.1%、36.1%。三個網格皆支持改善方向，但絕對局部數值仍對網格敏感；沒有完成網格獨立性證明。

| 最細0.2 mm網格，換算1 mL/min | 無擋板 | 選定台階 |
|---|---:|---:|
| 最差井口向下動量代理值，N | 1.058e-17 | 6.767e-18 |
| 最差井近液面速度P95，mm/s | 0.000970 | 0.000775 |
| 氣蓋內壓差，Pa | 0.008537 | 0.008607 |
| 四井向下循環通量CV | 0.0098 | 0.3691 |

台階改善方向性指標，但四井氣體循環的對稱性變差。這個CV不是氣味濃度CV；這個速度指標本身不能宣稱四井濃度一致；新增氣相濃度分析見文末。最細網格的近液面速度降低約20.1%，仍不能轉換成細胞保護或暴露均勻性的證據。孔板在粗網格可降低近液面速度更多，也降低井口向下動量，但形成不易清潔的上層空間。設計選擇明確包含製造與清潔取捨，並非把所有指標都說成改善。

## 數值驗證

自寫三維D3Q19 BGK格子波茲曼法，雙精度；τ=0.8篩選，ρ=1.2 kg/m³、μ=1.8×10⁻⁵ Pa·s。固體與固定液面皆為半格反彈無滑移，入口／出口非平衡外推定壓。每200步檢查速度相對改變<2×10⁻⁵、進出口質量不平衡<0.2%，連續三次才算收斂。28次求解均達宣告標準；最大末次質量不平衡0.0444%。C#與NumPy管流速度相對L2差3.09e-12。圓管Hagen–Poiseuille流量誤差在τ0.8為2.54%，τ0.55為-1.13%。這些是數值檢查，不是儀器實驗驗證。

篩選使用小壓差求解，再依低Re線性近似換算至1 mL/min。另以τ0.55實際算出無擋板0.9400、台階0.9401 mL/min；台階Re=0.554，相對密度差約0.234%。這兩次實际流量很接近，動量比為0.641，支持導流效果方向相同。更改τ也改變階梯壁面誤差，因此不可說差異全部來自慣性。

三個網格未建立局部指標的網格獨立性，禁止把末位小數當精準預測。原始速度求解不含氣味傳輸；新增氣相模型見文末，仍不含溶入培養液、蒸發、液面變形、細胞損傷或濾器管路模型。氣蓋內壓差不能用來選泵；外部濾器可能主導阻力。入口絕對壓力、呼吸／溫控與細胞相容性仍須實驗。

最細網格的氣體空間體積約1.193 mL；在1 mL/min時，單純V/Q約71.6秒。這只是整體體積／流量尺度，不是四井濃度達穩態的時間，也不代表這段時間即可完成一次生物量測。量測視窗2秒與完整氣味暴露時間必須分開設定。

## 短期實驗

先只用水做漏氣／漏液與流量設定；不要把染色液流場當氣體流場的等效驗證。選定氣蓋與同幾何無台階對照，在同一流量測試讀值穩定性、四井反應時間／幅度的差異，每次保持液量、溫度、細胞批次相同。若沒有氣體濃度感測器，應表述為「整機暴露反應比較」，不可寫成已量測局部氣速或已驗證CFD。兩週內以確認沒有明顯非對稱偏差為優先；不必追求複雜流場量測。

## 新增：孔板掃描、近靜止氣體與物種擴散

原始28次速度求解完整保留；另執行18個孔板幾何與2個細網格。孔徑1.2/1.8/2.4mm、節距3.6/4.2/4.8mm、孔板底Z57.9/58.2mm形成真正3×3×2掃描。六孔總數固定，節距並非全板孔密度。最低粗網格J比0.0246，在0.2mm為0.0351；最大粗網格比2.489。小孔可壓低循環，卻不是細胞曝露更好的證明。維持可清潔平台CAD，不輸出額外選印孔板。

井內100µL液深8.93mm、真正井口以下氣隙3.57mm。選定平台近液面氣速P95約0.00049–0.00093mm/s（0.4mm網格）；以3.57mm尺度及D=10mm²/s，局部Pe約0.00018–0.00033。低Pe表示擴散主導，並非沒有氣味能進井。氣隙L²/D約1.276s；完整管口至氣室的FV階躍則NE近液面t90=149.55s，0.3mm網格152.09s。液體內到底部細胞是另一問題，見相鄰membrane分析。

新增氣相求解採保守有限體積、後向Euler、迎風對流、中心擴散，先投影插值面通量至離散不可壓縮；基準面通量修正L2為1.54%。入口濃度階躍1、初始0、出口對流且擴散無通量，固體及液面無通量。D=5/10/20mm²/s是未量測VOC的敏感性區間。最大相對質量帳誤差8.65e-12；1D解析平均濃度檢查絕對誤差0.000246；基準t90網格改變約1.70%、時間步减半約−0.20%。這不是完整網格獨立性或實驗驗證。
