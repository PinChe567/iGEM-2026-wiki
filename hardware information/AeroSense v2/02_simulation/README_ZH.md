## 三個不同的問題

1. **氣味到達井口上方的氣體空間了嗎？** 看氣相濃度的擴散／對流計算。示蹤粒子走得慢，不等於分子不能擴散。
2. **氣味到達井底細胞了嗎？** 使用者確認井底貼附細胞、每井100 µL；目前內截面4×2.8 mm，液深約8.93 mm。必須另外看液體傳輸假設與實驗，不能把氣相到達時間直接當細胞反應時間。
3. **光學系統能讀出螢光變化嗎？** 蒙地卡羅收光與條件式接收訊號比較只能提供預測。未知的實際LED功率、濾片、光電二極體、電路雜訊、細胞反應仍需量測。

PDMS的疏水性不能當成阻擋水蒸氣的證明。膜研究使用明示的傳輸參數與敏感度範圍；未量測的配方比例不能換算成已知滲透率。本套組沒有因加入膜的模擬就要求你購買或安裝PDMS。

## 重現

各區的 README 與 Figure Guide 列出套件及重跑指令。先在各區重建，再於本目錄執行 `python build_gallery.py` 更新總覽，於package根目錄執行 `python prepare_release.py` 更新檔案清單與ZIP。不得把合成訊號、假設性材料參數或模擬結果改標成實測。
