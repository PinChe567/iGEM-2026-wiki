AeroSense reusable record templates

These header-only CSV files and JSON Schema contain no measured data or invented interviews.

MEASUREMENT
Use one row per channel and time point. Identify independent biological replicates separately from fields/technical replicates. Preserve instrument values and units; keep processed values in a separate derived table joined by run, sample, channel and time. Record the blank run, exposure/gain and environment actually measured. Missing observations stay blank, never zero-filled. Required schema fields are the minimum identification and traceability fields, not evidence of calibration. For a completed run, replace the blank template with observations and validate numeric units, source hashes, and QC decisions. Do not compare differing exposure settings as raw brightness. No physical instrument run is represented by this file.

STAKEHOLDER DECISIONS
Use a role or consented pseudonym, not unnecessary identifying details. Separate participant feedback from the team interpretation; link to a consented record or internal evidence location. A planned follow-up is not completed validation. Blank rows do not imply consent or approval.

REUSE
These files accompany the Contribution page. A team-wide code/hardware license is still awaiting selection; no third-party rights are assigned by this template.
