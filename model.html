Model

From receptor-response patterns to interpretable odor representations

Proposed pipeline · no implemented code or verified metrics yet

Question and role in the project

Status Planned

The model track asks whether fluorescence-derived receptor-response vectors can be transformed into more separable odor codes by an antennal lobe (AL)-inspired contrast step and a mushroom body (MB)-inspired sparse projection before classification, and whether those stages improve separation relative to simpler baselines [1] Dasgupta et al., 2017 — full entry in References & Credits. . That question is also framed as Engineering cycle C1.

Decision supported (intended): which receptor-panel features, preprocessing choices, and decoding stages to keep, revise, or drop when building odor-pattern classifiers for AeroSense assays.

Consumers of the output (intended): the wet-lab team (panel composition and assay design), the hardware team (sampling and feature handoff), and future wiki readers who need a reproducible decoding method—not a black-box accuracy claim.

What would be done differently because of it: once evaluated, the model should change receptor selection, experiment design, or hardware sampling only when a documented metric comparison supports that change. No such closed feedback loop has been recorded yet; see How the model informed the project.

Biological language on this page is analogy. “AL-inspired” and “MB-inspired” mean computational stages motivated by insect olfactory motifs; they are not claims of biological identity to antennal-lobe or mushroom-body circuits.

Pipeline overview

End-to-end flow as designed for AeroSense. Stages are labeled by implementation status in this repository and related wiki scaffolding—not by proposal intent alone.

  1. Proposed Preprocessing — register raw fluorescence with metadata; apply documented baseline rules ( EXP-AS-07).
  2. Proposed Response-vector extraction — map each receptor channel’s time series to a fixed feature (proposal: normalized fluorescence change).
  3. Proposed AL-inspired processing — pattern normalization plus global and lateral inhibition for contrast enhancement.
  4. Proposed MB-inspired sparse representation — sparse random projection and threshold / winner selection toward a locality-sensitive binary code [1] Dasgupta et al., 2017 — full entry in References & Credits. .
  5. Proposed Classifier — similarity to reference codes and/or linear softmax readout (proposal); compare against simpler baselines (proposal names PCA and SVM).
  6. Proposed Evaluation / feedback — metrics, ablations, and engineering learn/change records on Results and Engineering C1.

Implemented No pipeline stage has an executed, versioned code path in this wiki tree. Contribution package pkg-model remains In development without a public entry point.

Preprocessing and response extraction

Intended path: convert continuous fluorescence traces into a fixed-length receptor-response vector before AL-inspired processing. Protocol scaffolding lives in EXP-AS-07; interface ownership is stated on Design. GCaMP-class fluorescence reporting is the sensing context for these traces [2] Chen et al., 2013 — full entry in References & Credits. .

AL-inspired layer

Analogy: insect antennal-lobe circuits can sharpen odor patterns through inhibition among channels, including roles for local neurons and projection-neuron pathways [1] Dasgupta et al., 2017 — full entry in References & Credits. .

Mechanism (computational): a proposed discrete-time update that (i) converts intensity-like vectors into relative pattern codes, (ii) subtracts a global activity term, and (iii) applies weighted lateral inhibition across receptor channels. This is an engineered contrast transform, not a biophysically faithful AL simulation.

MB-inspired layer

Analogy: Kenyon cells in the mushroom body receive sparse, expanded inputs and form sparse odor codes; computational work links this motif to locality-sensitive hashing [1] Dasgupta et al., 2017 — full entry in References & Credits. .

Mechanism (computational): project the AL-layer output y ∈ ℝN through a sparse random matrix into a higher dimension, then threshold to a binary code. This is a designed sparse expansion, not a claim that AeroSense reproduces biological Kenyon-cell physiology.

Results and limitations

Measured model performance, figures, and failure statistics belong on Results so this page does not duplicate every plot. Current limitation: the decoding pipeline is a documented design with proposal-draft mathematics; it is not an evaluated AeroSense classifier.

  • Equations 2 and 4 include explicit index/notation audit notes unresolved without code.
  • MB connectivity is described both as ~5–10 synapses per unit and as ~10% sparse projection in proposal text—only one rule should ship.
  • No train/validation/test leakage controls can be asserted without an implementation.
  • Edge-deployment, low-power, or superior-accuracy claims are out of scope until measured against baselines.
